Application Processing Dolby Digital or Dolby E Audio with Dolby Decoder Enabled3981450361950 Set dip switch settings according to figure 5 to decode Dolby Digital or E audio. Dip switch [5,6] (AES5 / AES6 Selector & Dolby Decoder Input Group Selector) selects the group location of the Dolby signal proceeded by the Dolby decoder. Dip switch 4 (Dolby Decoder Input AES Selector) selects the AES1 or AES2 location of the Dolby signal within the respective group. Embedded audio transitioning from Dolby to PCM/Compressed will automatically be detected and passed by the card using these settings. outputs AES1-4 will function according to table 2. AES5 and AES6 outputs will always function as the de-embedded output set by dip switch ⅚.

Creating Lt/Rt Downmix of the Main Audio Program using Dolby Decoder Toggle dip switch 2 to the ON position show in Figure 6, to create a Lt/Rt downmix of the main program (Program 1). A downmix will now be available on output AES4 OUT.

Figure 2. Rear Modules Board Installation Use the following procedure to install the M6202AE in an openGear Series frame. Refer to the User Manual of the openGear OG3-FR-C series frame to ensure that the frame is properly installed according to instructions. When using the M6202AE with the OG3-FR-C frame, please note that the even numbered slots are to be used. Plug the M6202AE modules into slots 2,4,6,8,10,12,14,16,18, and 20 for a maximum of 10 cards. Slot 1 is the left most slot as you look into the frame from the front. After selecting the desired frame installation slot, hold the M6202AE card by the edges and carefully align the card edges with the slots in the frame. Then fully insert the card into the frame until the rear connection plugs are properly seated on the midplane and on the rear module. This completes the procedure for installing the M6202AE in an openGear OG3-FR-C Series frame. User Controls User Control Diagram Figure 3. Card-edge User Controls LEDs The front-edge of the card features LEDs that display the status of the input signals. As selections are made in the menus, (refer to the subsequent chapter for complete menu descriptions), the LEDs display the status of the input signals. Remote Control General Information This card may be monitored by a remote computer through Dashboard version 2.2.1 or higher. This free configuration monitoring software is available to openGear users at www.opengear.tv and is compatible with operating systems such as Windows, Linux and Mac.

The Dashboard control system is built on Ethernet and TCP/IP, allowing remote access across both LAN and WAN architectures. Multiple frames and cards can be connected to multiple control and monitoring stations at once.
