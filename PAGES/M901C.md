Each input has its own preamplifier, allowing individual gain trimming and common mode balancing of the discrete source inputs.</p><p>The sensitivity controls are front panel accessible.  These continuously variable controls provide adjustment for input source levels from -10 to +10 dBu.  A mode selector is provided which gives the operator the ability to reconfigure the stereo source material in the following manner.</p><p>1)	Provide normal stereo.</p><p>2)	Feed the left input channel only to both the left and right outputs.</p><p>3)	Feed the right input channel only to both the left and right outputs.</p><p>4)	Combine the left and right outputs into a left plus right mono output.</p><p>The preamplifier outputs, once selected, appear at the module connector for the insertion of optional processing.</p><p>The cue buss feed is connected to the insert return line so that pre-fade listening of source material can take place before any input module level control.</p><p>Direct left and right channel outputs are provided at the module connector.  These direct feeds may be optionally used for multitrack applications or to feed the console mix-minus system.</p><p>The output from this module may be assigned to any or all of four stereo program busses.  These buss selectors are preceded by a centre detent balance control, giving the operator the ability to trim level imbalances between the left and right channel signals.</p><p>Two auxiliaries are also integral to the module, a monophonic and a stereo one.  Both are assignable individually pre or post VCA, and each auxiliary has it&#x27;s own level control and on/off control.</p><p>The module also contains a &quot;blind assignable&quot; monophonic post VCA buss output.  This buss may be utilized for use by the console mix minus system.</p><p>Unitary control of most module functions is also available at the module connector for machine control as well as external control inputs.</p><p>Outgoing control signals are furnished as open collector paths to control common when activated.  Comprehensive internal module logic allows intelligent control of external machines, with all outgoing control signals following module source selection (source A or B).</p><p>A momentary closure to control common (through an open collector transistor), is provided when the module is turned on or off for both the A or B source.  This totals four independent outputs, one start and stop signal for both the A and B module sources.</p><p>An additional sustained closure to common is provided for both the A and B input sources.  This closure is active when the main channel is on, and is  provided for external use.  These outputs are also internally assignable to one or all of three internal console muting busses.  These busses run to the M905 monitor modules in the console system for muting the monitor speakers.</p><p>The internal buss structure of the console includes a cue control buss.  If a module is assigned to this buss, putting the module into cue will activate the auto cue function in the M905A control room monitor module.</p><p>The lamp internal to the channel off button is uncommitted and is brought out on the module connector.  This is intended for utilization as a tally indicator for external machinery.</p><p>Module control inputs are also configured to activate when a closure to control common is provided.
