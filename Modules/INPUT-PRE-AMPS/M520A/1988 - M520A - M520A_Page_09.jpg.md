M524 MONQ INPUT MODULE
mono post fade feed is brought out to the edge connector for use with an exter- nal channel assign module:
LED Program and Overload level indicator monitors the audio level at the insert point (prefade). The green LED of this two colour indicator illuminates when the audio level is at Or above the nominal operating level of the module (0 dBm) If the audio level approaches the overload point then the green indicator extinguishes and the red indicator illuminates The overload point is set approximately 22 dB above the insert point operating level.
The Channel Onand Solo control functions and  tallies, as well a5  the tallies  of subassignments, input source selection; mixing attenuator active and prefade funct- ions are all fed to the console control system via the module control assembly.
The MSZOA Mono Input Module is packaged in a standard WBS module size of 1.60" wide x 14.15" high 6.50" deep:
The module derives its power from the console system bipolar +/-25.volt and 12 volt power supplies.
