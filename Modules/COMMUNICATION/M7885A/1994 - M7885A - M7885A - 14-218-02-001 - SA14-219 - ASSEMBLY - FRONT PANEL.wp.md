The M7885A Assignment Terminals are used to re-assign IFB program sound feeds from remote locations, instead of using the central assignment computer.

It uses an adaption of the M7885 communica­tions system assignment ter­minal.

As many as four M7885A's may be connected to a MicroCOM II central matrix. IFB program sound feeds are assignable from the assign­ment terminals or the central assignment com­puter.  It is not the inten­tion that both  modes of oper­ation occur at the same time.

The assignment displays of the M7885A's are blanked off any time an assignment down load is made from the central assignment com­puter. Making an assignment change or setup on a M7885A assignment terminal transfers the IFB program sound control from the control tables associated with the central assignment com­puter function to those associated with the M7885A's. The 14 segment LED displays of a M7885A show the source codes of the pro­gram sound feeds assigned to the desig­nated IFB output buses. If more than one assignment ter­minal is connected to a communications sys­tem, the program sound source displays will show identical and current assignments (if the terminals are active). Mak­ing an assignment change on one M7885A will be reflected on the others.

With the release of software version ASPD up to 24 IFB outputs may be displayed. This is achieved with ́page ́ selection, page ́1 ́ shows IFB outputs IF01 through IF12 and page  ́2 ́ shows IFB outputs IF13 through IF24.

The M7885A is considered a dumb terminal,  with its assignments stored in the central matrix control system. The mnemonic coding of program sound sources and the IFB outputs normally are the default coding of PGM1 to PGM8 or PG01 to PG12 for sources and IF01 to IF24 for destinations. Alternatively the coding may be defined on a custom basis and set into the operating system software of the M7885A. These mnemonic codes are currently not re-programmable from the central assignment computer.

The 16 button keypad selector gives access to source/destination assignments, page selections and the defined mnemonic codes.

The M7885A assignment terminal makes use of the M7885 terminal hardware with specifi­cally designed operating system software. 

The M7885A connects to the central matrix via a single balanced serial data line similar to that used for all M7880 series of communica­tions terminals. It may be located up to 2 km (1.25 miles) from the central matrix.

The assignment terminal is a 3-1/2 inch high (2 rack unit) stan­dard 19 inch rack mount chassis. It is powered from a 115/230V AC 50/60 Hz power source.

The M7885A assignment terminal is of mod­ular design, with all active circuit components interconnected through ribbon type cables. This allows for easy removal of all electronics for service as required.

1)	DISPLAY WINDOW

The display window contains twelve four-digit 16 segment alphanumeric displays. The displayed codes show the assigned IFB pro­gram sources to the designated outputs.

2)	DISPLAY WINDOW

This display window contains two four-digit 16 segment alphanumeric dis­plays. These displays show which page of IFB destinations is selected (page 1 or page 2). When assignments are made from the key­pad, these displays will show the source and destination selections.

The display window will be blanked off when the terminal is not active (not on line) or if an assignment has been made from the central assignment computer.

3)	KEYPAD

The sixteen button keypad selector allows the IFB program sound sources to be altered for up to 24 IFB output buses in a MicroCOM II central matrix. The keypad buttons are organized as follows:

The right hand column of pushbuttons pro­vide for:
a)	SAVE	-	saving the setup  source/destination assign­ment.
b)	SRC	-	initiating the IFB program 	
sound source selection.
c)	DST	-	establishing the IFB bus des­ti­nation to which the source selection is being made.
d)	PAGE	-	the operation of this pushbutton alternate­ly dis­plays the IFB program sound sources for IF01 to IF12 for page 1 and IF13 to IF24 for page 2.

The lower left button of the keypad is the clear pushbutton (labelled ́CLŔ). Pressing this  pushbutton during an entry edit, will cancel the edit and Display #2 will return to display­ing the page number of the sources viewed in Display #1.

The keypad pushbuttons with the numeric labels may be predefined with possible mne­monic prefix codes for IFB program sound sources and destinations. As many as 18 prefix codes may be defined. Primary prefix codes are labelled in red above the pushbutton num­ber and secondary prefix codes  are labelled in blue below  the pushbutton number.

The  ́P ́ pushbutton toggles the selected ́Source ́ or ́Destina­tion ́ display entry between pri­mary (indicated with dashes) and secondary (indi­cated with dots) selections.

As shown the default assignments are both primary codes with pushbutton #1 labelled ́PGM - ́ for IFB program sound sources, and pushbutton #2 labelled  ́IF- - ́ for 24 possible IFB destinations.

Page Selections

Pressing the ́PAGE ́ pushbutton will alter­nately display the IFB program sound sources for IFBs 1 to 12 or 13 to 24. Display #1 shows the source selections. Display #2 shows the selectable page and the designation strips (4) labels the IFB outputs.

Destination Selection

Pressing the ́DST ́ pushbutton, displays four dashes above the  ́Destination ́ designation in display window #2. This is a prompt for a primary selection code for an IFB output, eg:  ́IF - - ́ on keypad pushbutton #2.

Upon entering the ́IF - - ́ prefix code into the destination display, the 2 remaining dashes  prompt for a numeric entry. The valid default numeric entries are 01 to 24 for the possible valid IFB's. Use the numeric labelled pushbuttons to make the entries.

Source Selection

Pressing the ́SRC ́ pushbutton will display four dashes above the ́Sourcé designation in dis­play window #2. This is a prompt for a pri­mary selection code for an IFB program sound source, eg:  ́PGM -  ́  on keypad pushbutton #1. Upon entering the  ́PGM - ́ prefix code into the source display, the remaining dash prompts for a numeric entry. For system IFB Mode oper­ation of  ́1́, the valid entries are 1 to 4, for Mode  ́2 ́ operation the valid entries are 1 to 8. A system Mode defini­tion of 3 requires the use of multiple prefix codes or altering the code to  ́PG - -  ́, with double digit numeric entries. This is to accom­modate twelve possible IFB pro­gram sound sources. These revisions are accom­modated on a custom basis to meet a customers specific require­ments.

If it is desired to cancel a pro­gram sound assignment to an IFB bus, select  ́SRC ́ and then press the  ́0 ́ pushbutton on the keypad. The source display will show  ́* * * * ́ for an indication that the program sound source for a particular IFB destination will be cancelled when the  ́SAVE ́ pushbutton is depressed.  
The source assign­ment for the selected destina­tion will blank off.

Save Selection

Operation of the ́SAVE ́ pushbutton will only be effective upon completion of valid source and Destination entries. This pushbutton selection will transfer the new source to the selected destination.

If no action is taken after making desired source and destination entries they will cancel out and Display #2 will revert to displaying the currently selected page on the M7885A. The time out period is in the order of 20 to 30 seconds.

Program sound source assignments may only be made on the currently selected page.

Initial Inspection

After removal of all packaging material, inspect the Assignment Terminal for any loose components or for any physical damage that may have occurred in transit. If there is any damage, contact the carrier and file a claim immediately. Do not discard packing material until the carrier or his representative has noted the damage.

The M7885A is normally supplied with a 9 pin D connector, for the serial data port.

Determine the following:

1)	The keypad and designation strips are labelled according to the systems defini­tion requirements, or to the default generic terms.

2)	The correct software version is installed as per MicroCOM II systems summary (refer to system manuals for detail). 

Power Requirements

The M7885A operates directly from the AC power line. The integral modular power supply is accessible by removing the top and bottom covers of the terminal.

Note: Service and adjustment of the power supply should only be performed by personnel knowledgeable with the technology employed, and with the correct isolated power sources and test equipment. High voltages are present and extreme caution must be taken.

The power supply will accept either 115V or 230V AC but may have to be strapped inter­nally for the required operation. Refer to section C of this manual for the type of power supply installed and the required strapping. The terminal, when supplied with a communi­cations system, will normally be strapped for the customers AC power source.

Note: the power supply will be damaged if jumpered or strapped for 115 volts and oper­ated on 230 volts AC.

Mounting:

The M7885A is designed for standard nineteen inch rack mounting, requiring two rack units of vertical space (3-1/2 inches). The depth requirement with connectors in place is in the order of 12 inches (305 mm). The M7885A weighs 11 lbs. (5 kg.).

Matrix Connections:

The M7885A Assignment Terminal connects to the central matrix via a single pair data cable. Belden audio cable 8451 may be used for this data connection. Refer to page 6-1 for data connector layout details. Insure that the phase of the serial data pair is correct and the com­mon return (shield) is connected throughout. 

The assignment terminals are connected to any­one of the last four data ports of the cen­tral matrix. Ports 45 to 48 for a 48x48 system, or ports 93 to 96 for a 96x96 system. If the audio inputs and outputs are required as well as the serial data port, a  ́Y ́ type cable connection may have to be made or parallel data port connectors installed. Refer to system intercon­nect drawings for detail.

Caution: Do not make cable solder connections with connectors installed and power applied to the assignment terminal or the central matrix. Data port devices could be damaged via power line leakage from soldering tools.

Assign Terminal Setup

The IFB matrix bus definitions and IFB pro­gram sound Mode definitions must first be made from the central assignment computer. This information must be sent to the MicroCOM II central matrix as part of the overall system configuration.

After the initial IFB system setup it will be necessary to manually enter a full set of assignments from the M7885A with it con­nected on line to the system.

The IFB program sound assignments from the M7885A are retained in memory in the M8504B input controller. These assignments in turn are passed on to the M8506B output con­troller, where they  are acted  upon.

IFB program sound assignments may originate either from the M7885A or the central assign­ment computer, but not concurrently. The intent is to use one or the other, but not both.
The assignment displays of the M7885A will blank off (after approx. 5 sec) if IFB program sound source assignments are  made from the central assignment computer, as they become indeterminate.

Making an assignment to any IFB output from the M7885A results in all assignments originat­ing from the assignment terminal and they will be changed accordingly.

To assist in setting up the IFB program sound assignments on the M7885A, any keypad oper­ation will result in the displays being active for approximately 30 seconds. This applies whether the terminal is on line or not.
