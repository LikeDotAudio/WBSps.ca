Changes in each version

What changed, in the words of the listing, oldest first.

  • AMS4V203 — 2002|35 · 2002-06-19 — AMS4(demux3) · PIC16F874: UPDATED FOR NEW ISSUE 5 PCB
  • V050000 (AMS4V500) — 2013|46 · 2013-11-25 — AMS4(demux4) · PIC16F874: Updated for using new demux4
  • 02AV0100 — 2013|46 · 2013-12-12 — DEMUX-4 FOR AMS4 UNITS: based on 02VA0000, Atmel Changed to accomodate AMS4 control
  • 02AV0101 — 2014|47 · 2014-09-17 — DEMUX-4 FOR AMS4 UNITS: Fixes the bug that happens sometimes by resetting the power where the demux board doesn’t lock, to resolve it generates a watchdog reset, it should be implemented in other versions as well.

No change note in the listing for: AMS4NV100.
