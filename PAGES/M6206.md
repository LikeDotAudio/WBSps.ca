## What it is

openGear card made for Astral Media: an EP1C12 FPGA de-embeds one SDI audio group and feeds the Dolby E/AC-3 pair to a CAT552 decoder, an ADSP-21262 SHARC mixes an announcer’s voice-over into the decoded L/R(/C) and the PCM pair while ramping the programme down, and an AT90CAN128 runs the GPI state machine, LEDs and DashBoard. Modelled pass by pass from the v1.04 AVR code, the SHARC sample interrupt and the FPGA detectors, on the real ISS1 gerber artwork.

## In the simulation

- ISS1 card from the gerbers with live LEDs, DIP switch and a removable CAT552 module
- GPI-1/GPI-2 voice-over state machine with tallies, LED chirp and the 1RU control panel
- SHARC RampAudioCalc ramps, dim table, mix matrix and the 1- and 5-frame delay lines
- DashBoard-style window fed by REPORT_PARAM every 288 ms and SET/GET replies
- AVR → FPGA → SHARC 80-byte control path with the “V201” handshake
- 19 findings: DIP table vs code, no Mode 1, GPI-2 starts voice-over, unconnected SHARC reset
