M441M CHANNEL AMPLIFIER
DESCRiPTION: The M441M Channel Amplifier is a plug-in, high performance module which forms the foundation of sophisticated console systems. The module is designed to integrate with the Ward-Beck group of modular console components. The M441M Channel Amplifier provides the following major functions: preamplification of a microphone source selection of a line input sensitivity and phase reversal adjustment to either the mic or line source reverb send selection (pre or post fade) and mix control foldback select and mix control solo select channel "ON' switch booster amplification following the mixer attenuator The input selector switch provides microphone sensitivity selection from 7CdBm to 20dBm in steps of 1OdB, for a standard nominal output level of 1OdBm: The line input position provides a range of sensitivity from 1OdBm to +8dBm: Sensitivity adjustments made by the rotary selector are combination of pre- amplifier feed back and input pad selection. By this means, it is possible to improve signal to noise with decreasing input sensitivity as well as maintain the highest overall dynamic range for the channel amplifier input circuitry. The microphone input is designed for operating from a 150 ohm source and the line input is designed to operate from a 600 ohm source or lower_ Both inputs are balanced to ground with the microphone input providing an input impe- dance of 1500 ohms or greater to the source and the line input a 20k ohm bridge to the source The M441M is entirely balanced, and is particularly immune to radio frequency interference in high fields. The maximum preamplifier output capability of +25 dBm provides a headroom of 35 dB before the fader_
FEATURES:
Modular, plug-in construction faci- litates convenient future expansion of console input channels:
Multi-position input selector pro- vides sensitivity and automatic mic or line source selection.

Totally balanced circuitry provides transient free operation and offers high RF immunity_
