Software

Firmware for every Ward-Beck device in the engineering software listings: the microcontroller, FPGA and DSP parts in each one, every released version and what changed in it. 116 devices, 465 version rows.

Master copy: WBS - DATA SHUFFLER/WBS - #SOFTWARE LISTINGS OFFICIAL - FULL HISTORY - #Engineering_.xlsx (the FULL HISTORY workbook, last notes 2018|51). Checked row by row against WBS - DATA SHUFFLER/SOFTWARE LISTINGS - #Engineering.xls, the 2016-06-01 copy: see the two workbooks compared.

Every device page has a Software section (each part and its current version), a Versions section (every revision) and Changes in each version. Devices with no other files in the archive have a page made from the listing alone.

Programming the parts

  • Altera: Products with the EPC1S configuration device are programmed with Quartus on the lab computer (Tools → Programmer, "Active Serial Programming" instead of JTAG, a .POF file).
  • Lattice: Lattice LFXP3C parts are programmed with LSC ispVM (Scan, pick the device, open the .JED file, GO).
  • Sharc: Boot EEPROMs are programmed with ChipWin (.LDR files from the debug folder); AT25F512 parts with the VisualDSP++ Flash Programmer (session ADSP-21262, AT25F512 driver).
  • PIC: MPLAB IDE (8.36 / 8.43) with the ICD3 programmer; POD10 / POD10A / POD10R need MPLAB X.
  • Production programming files live under H:\Production\PFiles\…; the listing warns, again and again: do not use the working files — use the file in the specific folder.

How versions are numbered

  • ABB1V103, V103: the early form, product code + V + three digits (1.0.3).
  • 1.0.7.7, 2.1.1.9: product firmware version (PFV) on the revision sheets; 1.x for issue 1 boards, 2.x for issue 2, 3.0.0.0 the assigned-input switcher; C.1.0.x custom builds (CBC mode 6, Dome mode 5).
  • 06VA0000, 05AV0100, 02AV0000: the 2012|45 on form, two digits for the product (06 AMS8-1 / AMS16, 05 MLC8, 03 AMS8-2, 02 DEMUX-4) then AV + build. The sheet notes that 06VA… should have been written 06AV…
