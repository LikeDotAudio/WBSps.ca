## Changes in each version

_What changed, in the words of the listing, oldest first._

- **02AV0000** — 2013|46 · 2013-12-12 — _DEMUX-4 FOR AMS-8 AND MLC UNITS_: First version of demux4 created for AMS8 series
- **02AV0100** — 2013|46 · 2013-12-12 — _DEMUX-4 FOR AMS4 UNITS_: based on 02VA0000, Atmel Changed to accomodate AMS4 control
- **02AV0200** — 2013|46 · 2013-12-12 — _DEMUX-4 FOR XTM4 UNITS_: based on 02VA0000, Atmel Changed to accommodate XTM4 control
- **02AV0300** — 2014|47 · 2014-04-30 — _DEMUX-4 FOR DMS1 UNITS_: based on 02VA0000, Atmel Changed to accommodate XTM4 control
- **02AV0400** — 2014|47 · 2014-04-30 — _DEMUX-4 FOR MicroDemux UNITS_: NOT TESTED YET
- **02AV0001** — 2014|47 · 2014-06-03 — _DEMUX-4 FOR AMS-8 AND MLC UNITS_: Fixes the bug that happens sometimes by resetting the power where the demux board doesn’t lock, to resolve it generates a watchdog reset, it should be implemented in other versions as well.
- **02AV0202** — 2014|47 · 2014-07-15 — _DEMUX-4 FOR XTM4 UNITS_: Fixes the bug that happens sometimes by resetting the power where the demux board doesn’t lock, to resolve it generates a watchdog reset, it should be implemented in other versions as well.
- **02AV0101** — 2014|47 · 2014-09-17 — _DEMUX-4 FOR AMS4 UNITS_: Fixes the bug that happens sometimes by resetting the power where the demux board doesn’t lock, to resolve it generates a watchdog reset, it should be implemented in other versions as well.
- **02AV0401** — 2015|48 · 2015-07-09 — _DEMUX-4 FOR MicroDemux UNITS_: atmel changed to give individual control on each AES output. FPGA changed to silent the outputs when there is no lock
- **02AV0201** — undated — _DEMUX-4 FOR XTM4 UNITS_: fixed bug of loosing audio when doing failiur test
