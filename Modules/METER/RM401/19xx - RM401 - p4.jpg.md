```text
Simplified System adjustment and alignment
cont'd
b)
Connect audio oscillator to input with level adjusted to Odbm, 600 ohms . (The RM4O1 exhibits matching input impedance)
Adjust M401-1 front panel gain control (screwdriver adj.) to produce OVU with all M4O1-2 gate switches in the "OFF" position.
Set audio oscillator to ~2Odbm, 1Khz level. Turn M401-2 gate #1 "ON" . Adjust front panel gate threshold #1 (screwdriver adj.) CCW until indicator lamp comes on. If lamp is already illuminated turn CW until lamp is extinguished. Do not turn beyond critical setting.
Reduce generator output level to ~22dbm
Turn M401-2 gate #2 "ON" Adjust front panel gate threshold #2 as per procedure for #1
Reduce generator output level to -24dbm and repeat step (f) for this gate _
h)
Repeat consecutively for all gates with individual gate activation (lamp on) for the following levels:
Gate #1 Gate #2 Gate #3 Gate #4 Gate #5 Gate #6 Gate #7 Gate #8 Gate #9 Gate #10
level level level level level level level level level level
~2Odbm 22dbm ~24dbm 26dbm ~28dbm ~3Odbm 732dbm ~34dbm -36dbm -38dbm
1)
Note: The above thresholds may be varied to operate at any desired audio level. In each case, for the standard RM4O1 system, 2db Of noise suppression is introduced_
The internal adjustments relating to the M401-2 should not be disturbed. The system has been factory adjusted to optimum performance as described in step (h)
```
