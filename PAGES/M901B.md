<details><summary>Technical Data — 1937 words · 1995 - M901B - 14-280-02-001 - SA14-280 - INPUT AMPLIFIER - ASSEMBLY.wp, page 1</summary><p>M901B MIC INPUT MODULE</p><p>Input Sensitivity:		-70 to -30 dBm (ref. 150 ohm source).</p><p>Frequency Response:	+/-0.4 dB from 20 Hz to 20 kHz. +/-0.2 dB from 30 Hz to 20 kHz. Measured at direct output.</p><p>Noise:		Greater than 126 dB EIN (20 Hz to 20 kHz).</p><p>Harmonic Distortion:	Less than 0.2% from 20 Hz to -20 kHz Less than 0.1% from 30 Hz to -20 kHz. At 10 dB above nominal operating level.</p><p>Source Impedance:		150 ohms, balanced/ unbalanced.</p><p>Input Impedance:		1500 ohms, minimum.</p><p>Output Impedance:		Less than  60 ohms at insert and direct outputs.</p><p>Load Impedance:		Greater than 10K balanced at insert and direct outputs.</p><p>Output Level:		-6 dBu  nominal, unbalanced.</p><p>Logic Input Levels:		 Logic 0: 	0 to +1.75 volts dc.	 Logic 1:	+3 to +24 volts dc.</p><p>External Control Output:	Open Collector. Minimum Load Impedance:	600 ohms. Maximum Load Current:	30 mA. Maximum Supply Voltage:	+24 volts dc. Saturated Collector Voltage:	+2 volts maximum at 30 mA load.</p><p>Power Requirements:	+/-24 volts dc, 150 mA.</p><p>Ambient Temperature:	0 to 50 degrees Celsius.</p><p>Weight:		725 grams.  The M901B provides the microphone input channel facility for the Renaissance series of radio consoles.</p><p>The input source selector allows two separate microphone inputs to be connected to the input module.  Each input has its own preamplifier, allowing individual gain trimming of the discrete source inputs.</p><p>The sensitivity controls are front panel accessible.  These continuously variable controls provide adjustment for input source levels from -60 to -30 dBu.</p><p>The preamplifier outputs, once selected, appear at the module connector for the insertion of optional processing.</p><p>The cue buss feed is connected to the insert return line so that pre-fade listening of source material can take place before any input module level control.</p><p>Direct left and right channel outputs are provided at the module connector.  These direct feeds may be optionally used for multitrack applications or to feed the console mix-minus system.</p><p>The output from this module may be assigned to any or all of four stereo program busses.  These buss selectors are preceded by a centre detent panorama control, giving the operator the ability to pan the input source between the left and right channel of the console program outputs.</p><p>Two auxiliaries are also integral to the module.  Both are assignable individually pre or post VCA, and each auxiliary has it&#x27;s own level control and on/off control.</p><p>The module also contains a &quot;blind assignable&quot; monophonic post VCA buss output.  This buss may be utilized for use by the console mix-minus system.</p><p>Unitary control of most module functions is also available at the module connector for machine control as well as external control inputs.</p><p>Outgoing control signals are furnished as open collector paths to control common when activated.  Comprehensive internal module logic allows intelligent control of external machines, with all outgoing control signals following module source selection (source A or B).</p><p>A momentary closure to control common (through an open collector transistor), is provided when the module is turned on or off for both the A or B source.  This totals four independent outputs, one start and stop signal for both the A and B module sources.</p><p>An additional sustained closure to common is provided for both the A and B input sources.  This closure is active when the main channel is on, and is provided for external use.  These outputs are also internally assignable to one or all of three internal console muting busses.  These busses run to the M905 monitor modules in the console system for muting the monitor speakers.</p><p>The internal buss structure of the console also has a cue control buss.  If a module is assigned to this buss, putting the module into cue will activate the auto cue function in the M905A control room monitor module.</p><p>The lamp internal to the channel off button is uncommitted and is brought out on the module connector.  This is intended for utilization as a tally indicator for external machinery.</p><p>Module control inputs are also configured to activate when a closure to control common is provided.  The module can be turned on and off, the cue can be toggled, and the source can be selected between A and B by simply grounding the appropriate module connector pin.</p><p>Program buss assignment is also possible external to the module.  Again, a closure to control common will effect this assignment.  To change a previous buss assignment, the electronic latches require clearing before loading them with new buss assignments.  A closure to common will also perform this function.</p><p>External control of the VCA within each module is also brought out to the edge connector.  Application of a voltage between 0 and 5 volts DC will bring the attenuator from no external attenuation to full attenuation from the current fader position.  This feature can be of benefit for automated cross-fading. The M901B Mic input module is packaged in a 1.5&quot; wide x 16.2&quot; high x 6.6&quot; deep.</p><p>This module derives its power from the console system bipolar +/-24 volt power supplies. 1)	Source &quot;B&quot; Select</p><p>Depressing this momentary switch (SW2), enables the &quot;B&quot; input source and disables the &quot;A&quot; input source selection (if it was selected).  Double pressing the active switch will cancel the selection.</p><p>2)	Source &quot;A&quot; Select</p><p>Depressing this momentary switch (SW1), enables the &quot;A&quot; input source and disables the &quot;B&quot; input source selection (if it was selected).  Double pressing the active switch will cancel the selection.  This source is selected automatically when power is supplied to the module.</p><p>3)	P3 Select</p><p>Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 3 stereo buss in the console.</p><p>4)	P1 Select</p><p>This electronically latched, momentary switch, (SW12), assigns the stereo audio signal to the program 1 stereo mix buss.  This assignment is performed automatically on module power-up.</p><p>5)	Pan Co</p><p class="bp">Also: <a href="Boilerplate.md#bp-05bac6dd0710cdd7">specs boilerplate (5 devices)</a></p></details>
