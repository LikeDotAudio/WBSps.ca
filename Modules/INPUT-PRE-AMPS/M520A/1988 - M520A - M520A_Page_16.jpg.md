CIRCUIT DESCRIPTION
M5ZA MONO INPUT MODULE
ControL Logic
The details of the SA14-077 Control Subassembly are described under that particular section.
This unit contains the latching circuitry for both the Program Channel switch and the Solo switch: These latches may be controlled either locally by momentary push- button SW19 and SW2O, Or remotely through the console control system: DS4 is the Channel On tally and DSS is the Solo On tally.
Eight tally sense points are fed into the control system via the control assembly_
The SA14-077 is powered by +12 volts which appears at P2 pin Y. The logic control common connects to P2 pin V of the module connector_
Power_Supply_Decoupling
The +/-25 volts applied to P2 pins 21 and 19 is regulated down to +/-18 volts by an active decoupler consisting of Q12 through Q17 With their associated components Q14 and Q15 are current limit sensors for the positive and negative voltage supply rails.
The common return for the +/-25 volt supplies is at P2 pins 20 and X while the main frame chassis connection is at P2 pin 22.
The 48 volt microphone phantom power is applied to pin P2 pin 2 of the module connector;
