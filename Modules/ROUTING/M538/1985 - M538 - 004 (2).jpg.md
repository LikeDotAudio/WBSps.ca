M538A/M538B M538C SWITCHER MODULES
The M538 series of Switcher Modules provide additional selection to the inputs of the M520 and M521 Input Modules _
source
In the ST series of Stereo Television consoles the module space below the meter housing and inline with each input module strip is available for the inclusion of these preselect Switcher Modules.
The M520 Mono Input Module has two microphone and two Line source selection capabilities within itself _ Both the microphone and Line input capabilities may be expanded with the inclusion of an M538A 4x2 Switcher Module. One section may be used for the microphone channels and the other for Line channels Since the Switcher Module has two channel (stereo) selection capabilities, the switcher outputs may be connected to the and B inputs for the Mono Input Module. By this means it is possible to have eight additional inputs for both the microphones and for the Lines .
The M538B 4x1 Switcher Module is two channel preselector as well but with only four source selection pushbuttons_ This module would typically be used to expand the microphone or the Line inputs only of M520 Mono Input Module.
The normal practice of connecting these Switcher Modules into an audio console system is that of busing the {ine sources across two or more input channels, making all sources available at all times Microphones are typically connected on one to one basis to the studio wal box receptacles
The M538C is an 8x1 Stereo Switcher Module that may be used to expand the source selection capabilities of the M521 Stereo Input Modules . The switcher outputs may be connected to the or the B inputs of the Stereo Input Module. Again it is normal practice to bus the inputs across at least two preselect switchers so that all sources are available at all times
The M538 series of Switcher Modules are individually packaged in the standard WBS single module size of 1.60" wide 7.00" high 6.50" deep
