E) Crosspoint Data
The crosspoint bit pattern data at the output of the M771 Latch mod- ule is transferred to the associated M724B crosspoint module via 24 parallel data lines It is strobe into each selected crosspoint module for period of 400 microseconds approximately every 150 milliseconds Therefore the status of each crosspoint is refreshed at this rate, either being turned on or off _
The response time from activating Lever Key to the closure of crosspoint is in the order of 250 milliseconds This is combination of system control or reaction time along with the deliberate soft switching action of the crosspoint. This timing allows for necessary overlap of either muting and/or unmuting functions to minimize the possibil ity of regenerative feedback.
The Logic Levels into the M771 Latch module are standard SV TTL (positive logic) , while the logic Levels of the M771 Latch module outputs are at 12 volt Tevel The strobe select outputs switch as negative logic (from 12V down to Ov ) and the crosspoint control outputs are switched as positive logic Levels (O=OV crosspoint off, 1=12V crosspoint on )
Note: exercise extreme caution when operating this module on an ext- under card. Always turn off power before inserting or extracting this module via breaker SW2 on the module.
It is also necessary that the Frame Select switch SW1 is set to the correct code number for correct system operation.
