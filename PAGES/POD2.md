### Installation (2)

<details><summary>Connections — 368 words · 2014 - POD2 - MANUAL.docx, page 1</summary><p>(DB9F) Transit data from (3-TX+, 8-TX-) Receive data from (7-RX+, 2-RX-) Ground (5-GND)</p><p>The communication protocol is detailed on the following pages.</p><p>SERIAL PROTOCOL</p><p>1)     REQUEST STATUS</p><p>ACTION: Two bytes are sent</p><p>1st byte    11110000</p><p>2nd byte 00000000</p><p>RESPONSE: 1st byte (POD9 Status)</p><p>1 X X X X X X X</p><p>X=0 Slave switch not activated ────┘[6 5 4 3 2 1]</p><p>X=1 Slave switch activated └── Video Inputs 1 through 6</p><p>X=0 Video source not selected</p><p>X=1 Video source selected</p><p>2nd byte (POD2 Status)</p><p>0 X X X X X X X</p><p>X=0 Sum switch not activated ────┘[6 5 4 3 2 1]</p><p>X=1 Sum switch activated └── Audio Inputs 1 through 6</p><p>X=0 Audio source not selected</p><p>X=1 Audio source selected</p><p>Note:If POD9 is not present the second byte of response would read 0000 0000.</p><p>2)     SUM AUDIO Action: Two bytes are sent</p><p>1st byte    1 1 1 1 0 0 0 0</p><p>2nd byte 0 1 X X X X X X</p><p>[6 5 4 3 2 1]</p><p>└── Audio Inputs 1 through 6</p><p>X=0 Audio source not selected</p><p>X=1 Audio source selected</p><p>RESPONSE POD2 will send back the same status bits as shown in the REQUEST STATUS command.</p><p>NOTE: To cancel SUM MODE send command F0, 80 (HEX) followed by the desired switch command.</p><p>3)      SWITCH AUDIO AND VIDEO</p><p>Action: Two bytes are sent</p><p>1st byte    1 1 1 1 0 0 0 0</p><p>2nd byte 1 0 X X X X X X</p><p>└── Audio Input 001➩110 (1➩ 6) └───── Video Input 001➩110 (1➩ 6)</p><p>RESPONSE POD2 will send back the same status bits as shown in the REQUEST STATUS command. NOTE: If switching from SUM MODE send command F0, 80 followed by the desired switch command.</p><p>4)        SLAVE AUDIO AND VIDEO</p><p>Action: Two bytes are sent</p><p>1st byte    1 1 1 1 0 0 0 0</p><p>2nd byte 1 1 0 0 0 X X X</p><p>└── Input 001➩110 (1➩ 6)  RESPONSE POD2 will send back the same status bits as shown in the REQUEST STATUS command.</p><p>NOTE: The Slave indicator on POD9 may be turned on by sending the command F0, C0 (HEX) and turned off by F0, C7 (HEX).</p><p>GPI</p></details>
