DESCRIPTION: The M166A is a plug-in, PC card, module  containing a active summing amplifier designed to combine a number of input sources to a common output while ma intaining extremely high isolation between the input circuits. FEATURES:
Balanced configuration utilizing operational amplifiers
30 input summing capability to output
Dual differential operational amplifiers produce a balanced input via solid tantalum capacitors. Balanced IC amplifiers process the signal at the output +24dBm output capability is provided in order to realize maximum signal headroom throughout the system:
Operating mode determined by con- ditional strapping on frame receptacle
The M166A Active Summing Module is designed primarily for use within WBS audio console systems but will operate efficiently in any balanced system where multiple signal sources are required to be assigned in random or cumulative configuration to an output or mixer buss.
