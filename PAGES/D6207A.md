## Footnotes

1. **D6207A docs (TIM):** Card edge and rear panel artwork from the CorelDRAW files (2026|59): D6207A-card-edge.cdr in this folder (2008-05-08) and the 2012 openGear Rear Module Guide. — `#OPENGEAR #SERIES/D6207A  #Engineering #TIM #PCB/D6207A-card-edge.cdr`
2. **D6207A docs (TIM):** The guide puts Reserved on rear position 9 and Metadata OUT on 10; this plugin used to have them the other way round. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6207A - Rear Module Options.cdr`
3. **D6207A docs (TIM):** The 2007 sheet in this folder calls position 9 “GPI/O 1” and the module “T6305” (no A). — `#OPENGEAR #SERIES/D6207A  #Engineering #TIM #PCB/D6207A-T6305.cdr`
4. **D6207A docs (TIM):** This folder’s card-edge, T6305 and D6207A drawings (and their Backup_of_ copies) are byte-identical to the ones in the Master Functional folder. — `#OPENGEAR #SERIES/D6207A - #Master #OPENGEAR/D6207A - #Engineering/D6207A - #Functional/D6207A-card-edge.cdr`
5. **D6207A docs (TIM):** The MIB design note names d6207xInputStatus / d6207xInputStatusEvent, but the MIB has d6207xCardStatus / d6207xCardStatusEvent, and the note spells “d6207xCardMibCompiliances”. — `#OPENGEAR #SERIES/D6207A  #Engineering #TIM #PCB/Defining a D6207A MIB.doc`
6. **D6207A:** Card edge and rear panel artwork from the CorelDRAW files (2026|59): D6207A-card-edge.cdr (2008-05-08) and the openGear Rear Module Guide D6207A - Rear Module Options.cdr (2012-01-16). — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6207A - Rear Module Options.cdr`
7. **D6207A:** The card-edge drawing shows exactly seven LEDs: AES1, Dolby1, Error1, AES2, Dolby2, Error2 and COM Activity. — `#OPENGEAR #SERIES/D6207A - #Master #OPENGEAR/D6207A - #Engineering/D6207A - #Functional/D6207A-card-edge.cdr`
8. **D6207A:** The 2012 guide labels rear position 9 “Reserved” and 10 “Metadata OUT”; the 2007 sheet calls position 9 “GPI/O 1”. — `#OPENGEAR #SERIES/D6207A - #Master #OPENGEAR/D6207A - #Engineering/D6207A - #Functional/D6207A-T6305.cdr`
9. **D6207A:** The guide names the module T6305A; the 2007 sheet and the netlist say T6305. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6207A - Rear Module Options.cdr`
10. **D6207A:** In the Inkscape conversion of the 2007 T6305 sheet only the two input BNCs are drawn; positions 3–10 carry numbers and labels only. — `#OPENGEAR #SERIES/D6207A - #Master #OPENGEAR/D6207A - #Engineering/D6207A - #Functional/D6207A-T6305.cdr`
11. **D6207A:** D6207A-card-edge.cdr, D6207A-T6305.cdr, D6207A.cdr and their Backup_of_ copies are stored twice, byte-identical, in the Master Functional folder and the #TIM #PCB folder. — `#OPENGEAR #SERIES/D6207A  #Engineering #TIM #PCB/D6207A-card-edge.cdr`
