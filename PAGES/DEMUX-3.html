Changes in each version

What changed, in the words of the listing, oldest first.

  • DEMUX3V200-AMS4 — 2006|39 · 2006-05-05 — DEMUX-3 FOR AMS4 · ATMEGA128L: FIXED COMMUNICATIONS BUG FOR AMS4 (FOR ISSUE 1 & 2)
  • DEMUX3V202 — 2009|42 · 2009-05-19 — *DEMUX-3 FOR AMS8 (PLEASE USE DEMUX-3 TAB) · ATMEGA128L: FIXED PHASE ISSUE IN ALTERA BETWEEN EMBEDDED AES STREAMS
  • 2.0.0.3 — 2009|42 · 2009-08-24 — DEMUX-3 FOR AMS8 UNITS: FIXED PHASE ISSUE IN ALTERA BETWEEN EMBEDDED AES STREAMS
  • 2.0.0.3 - POD19 — 2010|43 · 2010-07-05 — DEMUX-3 FOR POD19: Demux1 obsolete. Replaced Demux1 with Demux3 iss 4. Hardware modifications to remove RS485 transceiver to eliminate UART communication from Demux3 to POD19.
  • 2.0.0.4 — 2010|43 · 2010-08-18 — DEMUX-3 FOR AMS8 UNITS: Altera: Audio artifacts on AES4 ch2 on some of the demux boards, but not all. This problem was seen by bob on issue2,3,4 demux3 boards. Problem was resolved within FPGA
  • 2.0.0.5 — 2011|44 · 2011-04-06 — DEMUX-3 FOR DMS-1 UNITS: Atmel based on V200-4, corrected the communication procedure and wrong device type
  • 4.0.0.0 — 2011|44 · 2011-08-16 — DEMUX-3 FOR DMS-1 UNITS: Atmel based on V201-4 to correct the communication problems the previous version had
  • 4.0.0.0 — 2012|45 · 2012-04-27 — DEMUX-3 FOR XTM4 UNITS: Fixed bug with front panel freezing when SDI is selected. This is the same version that works with DMS1
  • v400 — 2012|45 · 2012-04-27 — DEMUX-3 FOR XTM4 · ATMEGA128L: Fixed bug with front panel freezing when SDI is selected. (see DEMUX3 TAB)
  • DEMUX3V203 — undated — *DEMUX-3 (PLEASE USE THE DEMUX-3 TAB) · EPC1S: FIXED PHASE ISSUE IN ALTERA BETWEEN EMBEDDED AES STREAMS

No change note in the listing for: DEMUX3V201-AIP8-2A, DEMUX-3 FOR DMS1.
