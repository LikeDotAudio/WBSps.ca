M8203
Oscillator Module
General Description The M8203 oscillator module is designed to provide reference tone of either 40OHz or 100OHz for alignment and test within an audio system.  Reference Bveposee are factory calibrated; frequency and amplitude outputs are programmable via Berg style connectors mounted directly on the PC board module: Three line level voltage source (low Z) outputs are available; 0, +4 and +8 dBu and one -60 dBm, 150 ohm output is provided for calibration of microphone input circuits.
The unit mounts in a standard Ward-Beck MF-82 31/2" rack-mounting frame, and is fully compatible with the D8212 DA package. It can be mixed and matched with all 8200 series Preamplifiers, Distribution Amplifiers and associated modules.
