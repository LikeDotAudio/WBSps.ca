POD16
STEREO AUDIO FADER

This is one of many in our line of top quality, low-cost broadcast problem solvers.  PODS are compact, rugged and affordable. They are suited for tabletop use, or rack-mountable singly or in pairs, in any combination.


POD16 is a unity gain two by one stereo audio fader. Connections to POD16 are on the rear panel via two rows of screw terminal blocks.  

POD16 offers 4 transition modes; manual, linear voltage cross fade, linear dB cross fade and linear dB V-fade. Transition times for all modes is set by a front panel trim control which is variable from 10mS - 2 seconds. Mode selection is made from front panel pushbuttons while input selection can be from the front panel or by external tally inputs available on rear panel terminal blocks.  The front panel pushbuttons and the external tally inputs can override each other.  The most recent event will be activated. 

POD16 can also be supplied with a RS422 serial control port; consult the factory for this option.  
Manual Mode - when in manual mode, POD16 input selection is made only from the front panel pushbuttons.  If POD16 is not in manual mode, the front panel input select pushbuttons will be locked out and the external tally inputs are used for input selection.  
Note : Only one external tally input should be used to activate crossfades; if both tallies are active, POD16 will fade both inputs in.

Linear Voltage Mode X-FADE - in Linear Voltage mode POD16 will X-fade between inputs one and two in a linear voltage fashion.  The transition time is set by the 'Fade Time' trim pot. In this mode, external control tally 1, when activated, will cause input 1 to fade in and input 2 to fade out. External control input 2 will cause input 2 to fade in and input 1 to fade out. External control tally inputs require  maintained inputs to select an input (ie: a positive voltage on the WET input or a ground on the DRY input will fade the input up, releasing these inputs will fade the input down. 

Linear dB Mode X-FADE - in Linear dB mode POD16 will X-fade between inputs one and two in a linear dB fashion. The transition time is set by the 'Fade Time' trim pot. In this mode, external control tally 1, when activated, will cause input 1 to fade in and input 2 to fade out. External control input 2 will cause input 2 to fade in and input 1 to fade out. External control tally inputs require maintained inputs to select an input (ie: a positive voltage on the WET input or a ground on the DRY input will fade the input up,releasing these inputs will fade the input down).
.

Linear dB Mode V-FADE - in Linear dB mode POD16 will V-fade between inputs one and two in a linear dB fashion. The transition time is set by the 'Fade Time' trim pot. In this mode, external control tally 1, when activated, will cause input 1 to fade in and input 2 to fade out. External control input 2 will cause input 2 to fade in and input 1 to fade out. External control tally inputs require maintained inputs to select an input (ie: a positive voltage on the WET input or a ground on the DRY input will fade the input up, releasing these inputs will fade the input down).
