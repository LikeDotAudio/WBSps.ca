R204
      STUDIO MONITOR MODULE
The R204 module provides studio monitoring and talkback selection
for the console. This module is equipped with an eight input, two
output balanced stereo audio switcher and has two banks of 8 front
panel switches for independent monitor selections for two studios.
All audio connections are made via convenient pluggable screw
terminal blocks.

The monitor outputs for studio 1 and 2 each have a front panel
volume control and a talkback enable pushbutton. The talkback audio
is fed internally via the R251 motherboard from the R206 to the
R204. When talkback is enabled, the right monitor output is
diminished by xxdB and the talkback audio is inserted at full level.
The talkback audio may also be enabled externally via the R206. The
monitor outputs may be muted by the mute buses A, B or C on the
console. Shorting jumpers on the main circuit board allow for easy
configuration of this feature.
```

R204 PROTOCOL

The R204 is connected to an internal RS485 serial communications bus. The serial bus is accessible from
the RS422 serial port on the R206 utility module; the R206 controls the RS485 bus. Each input module
position has a unique 5 bit address (0-27) which is read from the console motherboard while the studio
monitor address is always 29. The protocol is a two byte protocol and is defined below, all commands must
be 2 bytes. The R204 will respond to all commands by returning its status as detailed below. Polling is
accomplished by sending a command with the take bit cleared.

1st byte - Address Byte
                                1XXX XXXX

                                1 - always one for address byte.
                                X - Spare
                                 XX XXXX =01 1101
                                Binary module address 29

2nd byte - Command Byte
                                 0XXX XXXX
                0 - always zero for command byte.       X - take
                X - studio2\1                           X - in2
                X - spare                               X - in1
                X - spare                               X - in0

Commands
     When take bit is set input specified by binary number in2-in0 is selected.
     When studio 2\1 is set studio 2 is selected, when clear studio 1 is selected.
     The R204 always responds with the status of the studio last addressed.
```
