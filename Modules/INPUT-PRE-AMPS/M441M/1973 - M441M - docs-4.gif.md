Circuit Description
The M441M Channel Amplifier provides the following major functions:- preamplification to a microphone source 3 selection of a line input sensitivity and phase reversal adjustment to either the mic or line source reverb send selection (pre or post fade) and mix control foldback select and mix control 3 shloneeleot' switch booster amplification following the mixer attenuator For the following description please refer to drawings :-
B441-02-013 B181-02-001 B182-02-001
The microphone input is coupled through the module edge connector (pins 1 and A) to sensitivity switch Swl as in the line input coupled through bridging resistors Rl and R2 from the edge connector (pins 5 and E) to sensitivity switch Sw1
Switch decks A & B of SWl provide microphone sensitivity selections from -70dBM to -20dBm for a standard nominal output level of -l0dBm and sensitivity selections from -l0dBm to +8dBm for line inputs _
The microphone input is designed for operating from a 150 ohm source and the line input is designed to operate from a 600 ohm source or lower_ Both inputs are balanced to ground with the microphone input providing an input impedance of 750 ohms or greater to the source and the line input a 20K ohm bridge to the source_
Sensitivity adjustments made by Swl is a combination of pre- amplifier feed back and input pad selection . By this means , it is possible to improve signal to noise with decreasing input sensitivity as well as maintaining the highest over all dynamic range for the channel amplifier input circuitry_
