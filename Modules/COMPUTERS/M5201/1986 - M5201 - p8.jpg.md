GENERAL
M5201 MACHINE CONTROL MODULE
The M5201 Machine Control Module provides thirty-two unitary control inputs and thirty-two unitary tally outputs to and from the M5200 microprocessor based control system  Optional alphanumeric display drive functions are available when the control system operates in conjunction with WBS RS8024 Stereo Routing Switcher _
Two data ports are available for discrete control inputs Sixteen functions per port are provided. The inputs for these ports are isolated through optocouplers
Two data ports are available for discrete control outputs Sixteen functions per port are provided. The outputs for these ports are isolated with dry contact relay closures
Input and Output data ports are on 37 pin D ' fema connectors The M5200 interface connector and the input channel phanumeric displays (associated with the R58024 Routing Switcher) connector are 37 pin D ' male.
An optional display facility can also be accommodated within this module When interfaced with M5200 Controller Module, console input channel alphanumeric displays associated with the Rs8024 Stereo Routing Switcher will provide status display readout. This display facility is referred to as Option M5201/1 _
The M5201 is packaged in standard nineteen inch rack mount assembly occupying one rack unit of vertical space (1.75 inches and is sixteen inches deep
The M5201 is powered by an external 12 volt unregulated power supply The power to the machine control unit is via 15 pin 'D' male connector
2-1
