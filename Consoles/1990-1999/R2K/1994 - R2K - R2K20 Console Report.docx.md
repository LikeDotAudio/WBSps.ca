```text
R2K20 Console Report 


Modules in Console:

R205 Qty 1
R209 Qty 1
R221 (new issue) Qty 1
R201 (old issue) Qty 10
R202 Qty 1
R203 Qty 1
R204 Qty 1
R206 Qty 1


Most of the faders on the R201’s  (8 out of 10) are noisy when you move the fader up and down. The new R221 looks ok, as do the other 2 R201’s. Maybe we should replace all ten however?

On one R201 module the P2 and P4 switches do not work

On the R221 module the Ch On led inside the switch is not working

On the R203 and R204 modules there are a couple of buttons that you have to hit more than once for it to work

On the R204 module the T/B 1 and 2 buttons are intermittent

On the R206 module the timer controls buttons (all four) are intermittent

On the R206 module there are wires attached to the high side of the headset pot for both the L & R side and also the ground. The other ends are just hanging loose now.

There is a custom panel with two switches that I assume was once attached to the controls outs of the modules. Now the wires are just hanging lose.

One R201 module has one wire for the EOT switch removed

There is a lot of dust and crud on all modules and also inside the console that should be cleaned up. This might be causing the problems with some of the switches.

The R205 & R203 modules along with the console have custom idents attached. The R203 & R205 no longer have the normal ident holder or cover.

On the R206 module the paint on the two controls knobs is almost worn off 

The R221 module has custom software for the cough function

1 R201 has M101 software (pic16c65) the rest all have M102

R205 module has software V100 current is V105

R203 module has software V101 current is V106

R204 module has software V101 current is V104

R206 module has software V101 for U2 current is V103: software for U3 is V102 current is V103: software for U16 is V103 current is V104

 The PIC’S of the R205, R203, R204 and R206 are the old one time programmable type

The console ident paper and the R204 ident paper might have to be replaced
```
