M166A ACTIVE SUMMING MODULE
DESCRIPTION: The M166A is a plug-in, PC card, module containing an active summing amplifier designed to combine a number of input sources to a common output while maintaining extremely high isolation between the input circuits_ In addition, the module permits the summing of all inputs in the balanced mode and without loss of signal level_
FEATURES:
Balanced configuration utilizing operational amplifiers
30 input summing capability to 1 output
Dual differential operational amplifiers produce balanced input via solid tantalum capacitors_ Balanced IC amplifiers process the signal at the output: +24dBm output capability is provided in order to realize maximum signal headroom throughout the system_
Operating mode determined by con- ditional strapping on frame receptacle
The M166A Active Summing Module is designed primarily for use within WBS audio console systems but will operate efficiently in any balanced system where multiple signal sources are required to be assigned in random or cumulative configuration to an output or mixer buss_
Greater than 9OdB isolation between inputs 2OHz to 20kHz
Less than 25%THD at +24dBm output
Exceptionally low noise
