The M7882/M7883 Remote Communicat­ions Package has been designed to ope­rate as an active intercom terminal in conjunc­tion with the WBS MicroCOM ll Commu­nicat­ions System.

The M7883 Remote Communications Panel has the added advantage of being able to be remotely mounted when space limitat­ions are at a premium. Connections to the main M7882 terminal are made via inter­connecting cables.

The self powered M7882 contains the required audio amplifiers and microprocessor con­trol system to handle all control and communication paths to and from the central switching matrix.

The M7883 provides an integral dynamic gooseneck microphone, loudspeaker and headset select facilities. Ten programmable talk keys, ten listen select pushbuttons, four character alphanumeric displays and an assignment keypad are included.

The control assignment,and programming data is transferred to and from the matrix on a balanced serial data line which oper­ates on a RS422 format. The audio input and the audio output of the M7882 are balanced +8 dBm (+4 dBm optional) 600 ohm lines. The above three balanced lines allow full communi­cation between the terminal and the cen­tral matrix. Additional inputs, outputs and control functions are made available  on con­nectors at the rear of the M7882.

Audio from the remote dynamic or exter­nal headset microphone is amplified to a nominal +8 dBm (+4 dBm optional) line level output by a preamplifier. A front panel sens­itivity con­trol (SENS) is provided on the M7882 to make up for operating technique variat­ions. Input levels over a sensitivity range of 30 dB may be accommodated.

An auto levelling type limiter stabilizes the audio output from the microphone pre­amplifier, assuring constant system levels over a large range of voice vari­ations. Two level indicators on the M7882, located above the sensitivity control, are provided. One, labelled NORM (normal) flashes when the preamplifier output is a nominal +8 VU (+4 VU optional). The other, labelled OVLD (over­load), flashes when the limiting action becomes excessive (greater than 20 dB).

A third indicator, labelled XMIT illumi­nates when a talk keyswitch is operated, serving as a transmit tally.

The front panel "Enable" keyswitch is programmable to provide a "Lock Key Enable" or "Hot Mic" operation.

The external footswitch is paralleled to the "Enable" switch in the "Lock Key Enable" mode so that either switch enables the lock keys. 

In the "Hot Mic" mode the external footswitch function is in series with the lock talk keyswitch functions. If an ex­ternal footswitch is not used with a com­munications terminal, an external jumper must be added across the external footswitch connection.

A power amplifier boosts the incoming audio signal from the matrix and drives an integral speaker through the front panel speaker level control. This ampli­fier is capable of delivering up to 3 watts into an 8 ohm load.

The M7882 is powered from a modular power supply integral to the terminal and operates from either 115/230V AC 45 to 400 Hz. The integral power supply may have to be strapped for the specific source voltage being applied.

The M7882 and M7883 are individually housed in a 3 1/2 inch high, (two rack unit), aluminum chassis and designed for standard nineteen inch rack mounting. The M7883's shallow depth (approximately 3 in­ches), permits the remote panel to be easily mounted in most television plant operating areas. It is constructed on a modular philosophy. All active circuit modules interconnect through ribbon cables and chassis con­nectors allowing easy re­moval of all com­pon­ents from within the terminal as required for ser­vice.

This allows a preset group of latching talk keyswitches to be operated as a single function, either by operating the Enable momentary key or the external footswitch. Selecting the Lock Enable Key permits the Lock Talk Key­switches to operate their assigned Talk functions.

Alternatively when the ENABLE key- switches are placed in the HOT MIC Mode (see assign code PD37) the lock­ing talk keyswitch functions loop through the external footswitch con­nection (see page 8-2).  From the crosspoint control point of view the locking talk keyswitches are in series with the external footswitch control. Selection of the Enable/Hot Mic switch parallels the footswitch function.

In the HOT MIC Mode of the Enable keyswitches, the latching or momentary Enable keyswitch function must be selected before audio will be fed to the matrix  from the communications ter­minal.

The 1 to 6 keys have indirect ac­cess prog­ramming capa­bilities thr­ough the front panel keypad P push­button (see Keypad). Any time a keys­witch is acti­vated and audio from the micro­phone pre­amplifier is transmitted the speaker out­put is part muted. Calling Tallies:

The M7883 terminal features exten­sive call indicating cap­abilities.

These may be grouped into calling tallies, automatic call assignment for keys A to D and a call waiting fea­ture.

When an incoming call is rece­ived from a station, which is currently assigned to any one of the intercom keyswitches, the associated calling tally will blink. The calling tally indi­cators are located in the cap of the listen push­buttons above the alpha­numeric display.

Two colour LED's are used. They illuminate green to indi­cate that the listen function is selected, or red as a calling tally indicator. The calling tally has priority over the lis­ten indi­cator. Therefore if the listen push­button is on (green LED), the red blinking tally will over­ride the listen tally for the duration of the call.

The call is answered by pressing the respective momentary talk keyswitch. A call will also be answered by turn­ing on its locked keyswitch, (if the Enable key is on). Upon reply­ing to the call the tally chan­ges from blink­ing to a solid red indi­cator.

If a call is received from a station which is not currently assigned to any intercom keyswitch, the calling station code is displayed, flashing in the first empty window from D to A. By answ­er­ing the call (pressing the approp­riate intercom key) the stat­ion code stops flashing and is auto­mat­ically assigned to this key. During the assignment update, the display shows "****", when the station code returns the connection path is established.  Up to four calls may be received at the same time in this man­ner, pro­viding that keys A to D are pres­ently not as­signed.

If the A to D intercom keys are occupi­ed with as­signments, add­itional incom­ing calls are cap­tured by the "call wait­ing" fea­ture. This feature is enabled or disabled by assign code PD31.

With the call waiting feature enabled, an unassigned incoming call is indicated by the flashing "????" in the D key display win­dow. This is just a prompt to let the operator know that an unassigned station is calling.  The audio of the calling station will always be heard.

The call waiting buffer holds only the last call made.

To select the call waiting code press the "D" keypad pushbutton. The D display will now change to the flashing call waiting code. Pushing the "D" pushbutton a second time results in the D display returning to the current assignment alter­nating with question marks.

With the flashing call waiting code selected in the D window and operating the D talk keys­witch results in the D key taking on the call waiting assignment. This is as previously described for unas­signed A-D displays.

To recover the original D key assignment press the "D" keypad pushbut­ton again. The display blanks off momen­tarily and returns to the original D key assignment.

9)	KEYPAD

The sixteen button keypad selector allows direct prog­ramm­ing access of any valid station in the intercom matrix to keyswitches A, B, C and D and indirect programming ac­cess to keyswitches 1 through 6. The keypad is also used for switching between assignment pages or levels and main­t­enance related functions.

The keypad consists of sixteen push­buttons, which are orga­nized as follows: Buttons label­led A to D on the right hand side of the key­pad. These are used to change or make assign­ments to the correspon­ding inter­com keyswitches. Pressing one of these buttons will cause the display of the correspond­ing inter­com key to change to four dashes. This indicates that the terminal is ready to accept a new assignment for that key. If no other key is pressed within 15 seconds, the display  will return to the prev­ious assign­ment.

The lower left button of the keypad is the Clear key (labell­ed 'CLR'). Press­ing this key during an entry clears the assignment of the respe­ctive inter­com key.

The button labelled 'P' on the lower right next to the 'D' button is used for several programming type funct­ions.

The remaining keypad push­buttons are or­ganized similar to that on a telephone. The numeric buttons are labelled as fol­lows: But­ton numbers are printed in black in the center. Above it in red let­tering are the pri­mary key codes (the alpha-portion of the alpha­numeric station code). These are accessed dir­ectly after selecting an inter­com key. Below the numbers in blue letter­ing are the secon­dary key codes. The secondary key codes are accessed by pres­sing the 'P' push­button after the initial assign selec­t­ions. The 'P' pushbutton will tog­gle between primary (indicated by upper dashes in the ­display window) and secon­dary (indicated by lower or underline dashes in the display win­dow) codes. 

Keyswitches A to D Assignment

Press pushbutton A, B, C or D on the key­pad. The display above the select­ed keys­witch will change to four dashes, prompting for code input. If no other button is pressed within approximately 15 seconds, the display will revert back to the old assign­ment. If the 'CLR' button is pressed, the current ass­ign­ment is erased and the display cleared.

To enter a new assignment, press the numeric keypad pushbutton cor­respond­ing to the alpha-portion of the station's ID. If this is desig­nated in blue below the key number, press the 'P' key first to toggle to the secon­dary function. Note the dashes in the dis­play change to underline dashes.

After entering the alpha-portion of the code the following keypad push­button entries are the numeric digits. There may be either 1 or 2 digits or none if the mne­monic code already consists of four charac­ters.

Keyswitches 1 to 6 Assignment

The assignments to keyswit­ches 1 to 6 may be changed via the keypad for assignment pages or levels 1 to 3. In page or level 4 only assign­ments for keys A to D may be altered from the keypad. Normally, page or level 4 assignments are made from the central PC computer and uploaded to the res­pective terminals.

New key assignments to keyswit­ches 1 to 6 are made in the follow­ing manner:

Press the 'P' key. The 'A' dis­play window will change from showing its assignment to four dots. Don't worry about loosing the 'A' assign­ment. The assign­ment is unchanged and the display will be restored upon complet­ion of the data entry. The control system merely borrows the 'A' display as a prompt and a data entry area.
Press '0' followed by the num­ber of the key you wish to re-assign. Valid entries are 01 to 06.

After completing the second key stroke, the 'A' display cha­nges back to show the assig­nment of the A key, while the display above the selected key now shows four dashes, promp­t­ing for an assignment entry.

Proceed to enter a new assign­ment as described above (keyswitches A to D Assignment).

Numeric Entries

A keyswitch assignment may be made by bus number instead of the mnemo­nic code. Select the desired keyswitch to which the assignment is to be made, then press '0', the symbol # will be displayed as the first charac­ter in the assignment window. Then complete the entry of the 3 digit bus number to be assigned (e.g. #007, #023, etc).

Code Overlay

The electronic legending displays either the generic (or mnemonic) bus code, the bus number (prefixed by a # symbol) or code overlays. The code overlay is an alias of the generic bus code, per­sonalizing the coding for specific operational re­quirements. The overlay is selected by pressing the "P" button fol­lowed by "C" on the keypad. Repeating the above will toggle the displays back to their generic codes.

Station Identification

Pressing the "P" button followed by "9" on the keypad displays the bus number and the generic code (or its alias if in overlay mode) that the terminal is connected to on the displays above keyswitches A to D.

Pressing "P" "9" and viewing the stations ID will allow one to quickly determine whether the terminal is in its mnemonic bus code mode or the overlay mode.

Change, Copy or Delete Assignment Pages 
Up to four different sets of station as­signments may be stored in the M7882/M7883. These are known as pages or levels 1 to 4. By switching be­tween these pages, we can effect­ively change the key assignments to diff­erent preset con­figurations.

Pages or levels 1 to 3 are assigned via the keypad, while page or level 4 is assigned from the central assignment computer. It may also be sub­liminally re­assigned to different stations from the assignment computer while the ter­minal is operated from one of the other pages or levels. In page or level 4 only keys A to D may be reassigned from the terminal key­pad.

To change from the current assign­ment page or level, press 'P', fol­low­ed by the 'A' button on the keypad. The display above intercom keyswitch A will change to 'PG#X', where X is the cur­rently selected page (1, 2, 3 or 4). To select a new page or level, simply press a num­bered pushbutton from 1 to 4 to select the respective page or press 'CLR' to cancel the operat­ion. After selecting a new page or level, the displays above the inter­com keyswitc­hes change to reflect their new as­signments.

To copy the assignments of the current page to another, press "P" followed by "A" and "C" on the keypad. The displays above keyswitches A to D will change to "COPY PGX to PG _", where X is the currently selected page (1, 2, 3 or 4). The flashing underline symbol prompts for the page number to copy to (Pages 1, 2 or 3).

To delete the assignment of the current page, press "P" followed by "A" and then "D" on the keypad. The displays above keyswitches A to D will change to "** DELETING **" and then blank off.

Editing of Group (GRP) Assignments

Multiple crosspoint assignments may be made to a single talk key or listen push­button. These multiple assignments are known as groups and may be as­signed to any key, with the phantom mnemo­nic code of "GRP1" to "GRP4".

Each group (GRP) may consist of up to six codes each. The following outlines the selection or editing procedure.

a)	Press the "P" pushbutton, followed by the "B" (GRP) pushbutton. Display window "A" will show "GRP_", promp­ting for a group num­ber entry. Press a number push­button from 1 to 4, for Group 1 to 4.

b)	At this point the display windows 1 to 6 will show any previously defined as­signments, whereas displays B to D will display the talk, listen and listen/­mute crosspoint control attri­butes.
Note: "1" means the attribute is select­ed, "0" means the attribute is not select­ed.

The talk attribute is always set to "1", while the listen and the listen/mute at­tributes may be changed as desired. The listen/mute at­tribute will be "0" if the listen at­tribute is set to "0".

c)	To change the listen attribute, press the "C" pushbutton, followed by "1" or "0". Like­wise, to change the listen/­mute attri­bute, press the "D" push­button, followed by "1" or "0" (provi­ding the listen attri­bute is a "1").  It is necessary to always press "C" or "D" before pressing "1" or "0" to set or clear the attribute. When the group (GRP) edit and or attribute definition is complete press the "A" keypad pushbutton (SAVE) to save the entries and store them in memory.

d)	To edit or enter an assignment press the keypad's numeric entry buttons 1 to 6 for accessing display windows 1 to 6. A set of four dashes in the select­ed win­dow will prompt for an assign­ment selection in the same manner as a regular key assignment as described previously. Press the mne­monic code entry pushbutton first, then com­plete the entry with a one or two digit numeric entry, depen­dent on the code. Of course if the mnemo­nic code is a complete ass­ign­ment (such as MTCE, etc), no further key presses are re­quired. 

e)	To clear selected assignments, press "0" to clear the four dashes and blank the display.

f)	Define or redefine the assignments and control attributes as desired. When com­plete, press the "A" keypad push­button (SAVE) to save the group (GRP) definition. 

To exit the Group edit mode press the "CLR" pushbut­ton. The new defi­nition is not effec­tive until saved by pressing the "A" keypad push­button (SAVE). The Group edit mode automatically times out and ter­minates after approximately 20 to 30 seconds of ina­ctivity (no pushbuttons pressed).

It should be noted that after saving and returning to a group edit that the mnemonic codes may be shifted to their original entry position. This occurs if a blank (no edit) existed between previous­ly made entries.

Pressing the "CLR" keypad pushbutton at any time will exit the group (GRP) edit mode leaving the GRP as previously defined. It is necessary to press the "A" keypad pushbutton to save the group (GRP) edit entries. The group edit mode will time out in approximately 20 seconds after the last entry.

Phantom Code Selections

A number of select codes are available known as phan­tom codes. These codes do not directly pertain to individual crosspoints, but instead to tabled groupings of crosspoints. These tabled groupings of crosspoint control are known as:

Groups	GRP1 to GRP4
Call Arrays	CA01 to CA12
Camera Arrays	CMA1 to CMA8
ISO Select	IS01 to IS24
Event Control	EV01 to EV24

a)	Groups (GRP):

Four group assignments each consisting of six matrix bus codes may be defined within each communications terminal. The defining of these groups may be setup in the assignment computer and then fed to the appropriate com­munications ter­minal. 

As described above the groups may be defined and edited at the terminal. The last activity of the terminal groups determines the current as­signment. 

If a download from the central as­signment computer is made for groups, then that is the bus codes assigned to the groups. If a local keypad edit is made of the group assignments then the last chan­ges made will prevail as the group as­signment.

These group assignment setups are unique to each communications terminal.

b)	Call Arrays (CA):

Twelve Call Arrays (CA01 to CA12) each with a capacity of sixteen matrix bus codes may be defined and stored in the central matrix control system.  The definition of these arrays is established in the central assignment computer and subsequently loaded into the system.

The arrays are global in nature, that is selection and operation of a Call Array code by any communications terminal results in the operation of the appropriate talk and listen crosspoint for the matrix bus codes entered in the table.

c)	Camera Arrays (CMA):

Eight camera arrays may be defined (CMA1 to CMA8). This array definition as outlined in b) above for call arrays  per­mits defined keyswitch functions on a com­munication terminal to com­municate with a defined group of four wire camera circuits as if they were one.

Associated with this function are inter- camera party line, sidetone and isolate functions. Refer to the as­signment com­puter documentation for setup details.

As many as twenty-four cameras may be defined, with up to twelve cameras as­signed to any of the eight possible arrays.
d)	ISO Select (ISO):

This phantom code permits a selected camera to be removed from a defined camera array (camera isolate). Usually in a system only one or two communications stations have the camera ISO function enabled. This is determined by assign code PD32.

Refer to the MicroCOM II Com­munications System Handbook for il­lustrations and detail of the camera as­signment and isolate operation.

e)	Event Control (EV):

The MicroCOM II communications system contains what is referred to as Electronic Pegboard Control (EPC). This feature permits the selection and operation of matrix crosspoints on a co-ordinate basis and without as­sociation to a particular communications terminal.

Associated with the EPC is the Event Control. This is where a defined com­munications terminal keyswitch function (known as EV01 to EV24) may be desig­nated to  operate  numerous matrix crosspoints.

A more detailed description of the EPC function is outlined in the MicroCOM II Communications Systems Handbook.
