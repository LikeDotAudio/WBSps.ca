WBS Simulation Index

Interactive simulations of Ward-Beck Systems products, built from the firmware, FPGA projects, manuals and photos in this archive. Each one replays a single second in slow motion: what the device sees, what its displays show, how the operator used it, and how each button press travels through the code.

Open the simulator

Using a simulation

▶ Play / stepThe top bar plays the second at 1/60 speed or slower. Step moves exactly one unit: one video field, one loop pass, one AES block or one sample. You can also use the , and . keys.
Zoom windowSets how much of the second the timeline shows, from the whole second down to a few microseconds. Click the timeline to move the playhead.
Front panelClick a knob's left or right side to turn it and its centre to press it, or use the mouse wheel. The trace panel lists the firmware functions each action ran.
TutorialA guided set of operator tasks. Each step checks that you reached its goal and gives a hint if you haven't.
Real artworkPanels are built from the archive's own silkscreen separations, from the 2016|49 #ARTWORK #DA #2016 PDFs, in their real ink colours. Where there is no silk, they are drawn to scale from the mechanical drawings and photos.
“inferred”Marks a value that isn't stated in the archive and was worked out instead. Everything else comes from the source files listed on each Findings tab.

Adding a product

1 · Copy the templatesiumulation-plugins/_template.js → <id>.js. It lists the drawing and timing helpers the core provides.
2 · List itAdd an entry to siumulation-plugins/_manifest.json, then run node siumulation-plugins/tools/build_catalog.js. That regenerates plugins.js, which this page and the simulator read.
3 · Describe itFill in product, year, family, folder, summary, highlights, depth in SIM.register(); the catalogue copies them here.
4 · Preview itRun node siumulation-plugins/tools/make_previews.js <id>. It opens the simulation in headless Chrome and saves its front panel as previews/<id>.png for this page. Run it with no id to redraw every preview whose plugin has changed.
