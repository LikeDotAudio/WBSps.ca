The program that is loaded into the EPROM on the M774A input controller daughter assembly contains revised format routine (OUTBL ) that provides the operation of special crosspoint control functions_
These special control functions allow the NTC Supervisor station (bus 005 ) to operate total of 60 fixed lever keys on its associated bus In order to operate this quantity of fixed lever keys, two more input buses (bus 021 and bus 022 ) are dedicated to the supervisor station (bus 005 ) Key control from the 60 way Supervisor panel is connected to the communications terminal located on each of these two buses   The purpose of the revised format routine is to shift any cross- point operation that appears on bus 021 or bus 022 down onto the NTC Supervisor bus (005 ) thereby allow ing the Supervisor station (bus 005 ) to talk to any station that is assigned to one of its 60 keys.  -   ^   `  '   .
