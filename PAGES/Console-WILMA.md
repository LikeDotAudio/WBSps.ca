# WILMA

[← Console lives](Console-lives.md)

|  |  |
|---|---|
| Model | L3262 |
| Owner | APK |
| Kind | split L-series recording console |


The finest Ward-Beck L series console in the world: a joint venture between the Revolution Recording Custom Shop and APKaudio. 32 M470R, 16 M462B, 8 M462A, 8 M462, 4 M466, 16 M436L; full patchbay to EDAC, solo in place, stepped pre-amp gain, Mogami wiring, buffered VU on every input. The last WBS ever, with a custom WBS meter bridge.
