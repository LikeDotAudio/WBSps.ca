<details><summary>Technical Data — 1980 words · 1994 - M901NW - 14-281-02-001 - SA14-281 - INPUT AMPLIFIER - ASSEMBLY.wp, page 1</summary><p>M901NW CUSTOM LINE INPUT MODULE</p><p>Input Sensitivity:		-10 to +10 dBu. (ref. 600 ohm source).</p><p>Frequency Response:	+/-0.2 dB from 20 Hz to 20 kHz. Measured at direct output.</p><p>Noise:			Greater than 80 dB below nominal operating level, with the attenuator set for 15 dB &quot;in hand&quot; ( 20 Hz to 20 kHz).</p><p>Harmonic Distortion:	Less than 0.01% from 20 Hz to 20 kHz at 10 dB above operating level.</p><p>Source Impedance:		600 ohms or less balanced.</p><p>Input Impedance:		30,000 ohms, balanced.</p><p>Output Impedance:		Less than  60 ohms at insert and direct outputs.</p><p>Load Impedance:		Greater than 10K balanced at insert and direct outputs.</p><p>Output Level:		-6 dBu  nominal, unbalanced.</p><p>Logic Input Levels:		 Logic 0: 	0 to +1.75 volts dc.	 Logic 1:	+3 to +24 volts dc.</p><p>External Control Output:	Open Collector. Minimum Load Impedance:	600 ohms. Maximum Load Current:	30 mA. Maximum Supply Voltage:	+24 volts dc. Saturated Collector Voltage:	+2 volts maximum at 30 mA load.</p><p>Power Requirements:	+/-23 volts dc, 150 mA.</p><p>Ambient Temperature:	0 to 50 degrees Celsius.</p><p>Weight:			700 grams.  The M901NW is a custom M901C input module designed to provide dual stereo line level input facilities for the Renaissance series of radio consoles.</p><p>The input source selector allows two separate stereo inputs to be connected to the input module.  Each input has its own preamplifier, allowing individual gain trimming and common mode balancing of the discrete source inputs.</p><p>The sensitivity controls are front panel accessible and accommodate input source levels from -10 to +10 dBu.</p><p>The selected preamplifier output is routed to the module connector for the insertion of optional processing.</p><p>The cue bus assignment is directed from the insert return to the cue bus to allow pre-VCA monitoring of source material.</p><p>A direct left and right channel output is provided at the module connector. These direct feeds may be optionally used for multitrack applications or to feed the console mix-minus system.</p><p>The  module output is also assignable to any or all of four stereo program buses.</p><p>Two blind auxiliaries (one mono and one stereo) are also built into the M901NW. Both are pre-set to unity gain, and are assignable pre or post fader by appropriate placement of wire jumpers. The auxiliaries can be turned on and off in similar fashion.</p><p>A blind assignable monophonic post-VCA feed is assignable by a &quot;Berg&quot; jumper to the console mix minus bus.</p><p>Unitary control of most module functions is also available at the module connector for machine control as well as external control inputs.</p><p>Outgoing control signals are furnished as open collector paths to control common when activated.  Comprehensive internal module logic allows intelligent control of external machines, with all outgoing control signals following module source selection (source A or B).</p><p>A momentary closure to control common (through an open collector transistor), is provided when the module is turned on or off for both the A or B source.  This totals four independent outputs, one start and stop signal for both the A and B module sources.</p><p>An additional sustained closure to common is provided for both the A and B input sources.  This closure is active when the main channel is on, and is  provided for external use.  These outputs are also internally assignable to one or all of three internal console muting busses.  These busses run to the M905 monitor modules in the console system for muting the monitor speakers.</p><p>The internal buss structure of the console includes a cue control buss.  If a module is assigned to this buss, putting the module into cue will activate the auto cue function in the M905A control room monitor module.</p><p>A separate LED over the channel fader indicates when the channel has been turned on. Both lamps in the ON and OFF pushbuttons are connected to the edge connector for use as external tally indicators.</p><p>Module control inputs are also configured to activate when a closure to control common is provided.  The module can be turned on and off, the cue can be toggled, and the source can be selected between A and B by simply grounding the appropriate module connector pin.</p><p>Program buss assignment is also possible external to the module.  Again, a closure to control common will effect this assignment.  To change a previous buss assignment, the electronic latches require clearing before loading them with new buss assignments.  A closure to common will also perform this function.</p><p>External control of the VCA within each module is also brought out to the edge connector.  Application of a voltage between 0 and 5 volts DC will bring the attenuator from no external attenuation to full attenuation from the current fader position.  This feature can be of benefit for automated cross-fading. The M901NW Stereo Line Input  module is packaged in a 1.5&quot; wide x 16.2&quot; high x 6.6&quot; deep space.</p><p>This module derives its power from the console system bipolar +/-23 volt power supplies. 1)	Source &quot;B&quot; Select</p><p>Depressing this momentary switch (SW2), enables the &quot;B&quot; input source and disables the &quot;A&quot; input source selection (if it was selected).  Double pressing the active switch will cancel the selection.</p><p>2)	Source &quot;A&quot; Select</p><p>Depressing this momentary switch (SW1), enables the &quot;A&quot; input source and disables the &quot;B&quot; input source selection (if it was selected).  Double pressing the active switch will cancel the selection.  This source is selected automatically when power is supplied to the module.</p><p>3)	P3 Select</p><p>Switch SW14, a momentary switch with an electronic latch attached to it, controls the assignment of the module output to the program 3 stereo buss in the console.</p><p>4)	P1 Select</p><p>This electronically latched, momentary switch, (SW12), assigns the stereo audio signal to the program 1 stereo mix buss.  This assignment is performed automatically on module power-up.</p><p>5)	Q</p><p>This momentary electronic switch assigns the pre-fader signal to the console&#x27;s stereo cue buss.  This provides a pre-fade listen feed for cuei</p><p class="bp">Also: <a href="Boilerplate.md#bp-05bac6dd0710cdd7">specs boilerplate (5 devices)</a></p></details>
