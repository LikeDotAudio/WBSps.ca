OPERATIONAL DESCRIPTION
M5Z04 MONQ INPUT MODULE
Refer to Module Layout B520-04-001
1)
PAN SELECT
Pan insertion switch SW6 inserts the pan control into the left and right output signal paths of the module:
2)
PAD
Pad switch SW2 inserts a 20 dB loss pad into the microphone input signal path: This typically has application when condenser microphones are being used:
3)
MICLLINE
Mic/Line selector SW3 determines whether the input source material will be from the microphone Or from the line. When the switch is released the source selection is the microphone and when depressed it is the line.
4)
ALB
A/B source selector SWI when released selects the "A" source of the Mic or Line input determined by the setting of SW3. When depressed and latched the "B" Mic or Line source is selected.
5)
PHASE
Phase reversal switch SW4 reverses the phase of audio signal path through the M520 Input Module when depressed.
PHASE REVERSAL INDICATOR
Phase reversal indicator DS2 illuminates when SW4 is depressed.
PGMPEAK
This indicator DS3 illuminates green when the level of the audio signal at the module insertion point (prefade) is at or above the nominal operating level. The indicator will switch to red (overload) when the signal level reaches the point where it is approximately 22 dB above the nominal_
8)
AUXILIARY ON
Switches SW12, SW14, SWI6 and SWI8 assign the audio signal to the approp- riate auxiliary mix bus
