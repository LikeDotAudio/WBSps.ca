## What it is

This folder holds only the issue 2 and issue 3 pick-and-place programs for the D6203A openGear analog-to-AES converter. The plugin draws the board from those placements and runs the card itself (AK5394A, reference fallback, CAL) from the V104 firmware in the sibling D6203A folder.

## In the simulation

- Board drawn from the PNP program, issue 2 vs 3 diff
- Analog level → dBFS with H1/H2 headroom
- Reference fallback and chirp from the real 175 µs loop
- CAL self-calibration timing
- DIP switch and DashBoard
