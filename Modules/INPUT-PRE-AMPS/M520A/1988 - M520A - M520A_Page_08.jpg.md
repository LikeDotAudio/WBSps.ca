WAAD-BECK SYSTeMS LTD_

GENERAL
MSZA MONQ _INPUT MODULE
The MS2OA provides the monophonic input channel facilities for the ST series of Stereo Television consoles:
The module has transformer coupled input with source selection provided for two microphone and two line inputs Phantom power selection is provided for condenser microphone applications: The microphone inputs have an additional 20 dB loss pad, which may be selected for applications where higher than normal microphone input levels are experienced (such a5 condenser microphones)
The preamplifier has continuously variable sensitivity control covering 30 dB range: This allows the Level of the source material to be optimally set for operat- ion within the input module. 12 dB per octave High Pass   filter is associated with the preamplifier and allows selections of 75, 150 and 250 Hertz for the cut off frequencies:
An insert point is provided following the preamplifier for the MS22 Mono Equalizer; This equalizer is normally located immediately above the MS2OA Input Module on the ST series of consoles:
An actively balanced insert point; is also made available for the insert jackfield and the inline, balanced, slide mixing attenuator_ The Prefade Listen function precedes the Channel On selection. This permits the module source material to be monitored prior to it being processed by the module: Direct Output; prior to bus selectors and after pan pot; is made available on the module connector. This may be optionally used a5 direct feeds for multirack appli- cations Or to the inputs of an external switching system:
Four stereo  pushbutton bus   selectors are   provided: The module output may be selected to any or all of four stereo submaster  mixing buses: The bus selectors are  preceded by Pan control, which allows the operator to position the mono source as required across the stereo spectrum_
The Solo function take off point follows the Pan control as well: Therefore when Sole is selected, the module output is fed to the stereo monitoring system in the same relationship a8 it is to the console mixing buses
The Channel On and Solo functions of the MS2OA Input Module are made via solid state FET switches. This provides for very reliable and silent  switching: The Channel On and Solo controls may, also be controlled external to the module by the mixing consoles microprocessor based control system:
Four Auxiliary outputs are provided, each with a separate level control, assignment switch and pre/post fade selector: Auxiliaries 1 and 2 feed stereo buses, while Aux- iliaries 3 and 4 feed mono buses.
