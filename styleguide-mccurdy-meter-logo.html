03 / Typography & Letterform Anatomy

Optical sizing and casing specifications for the "McCURDY" logotype

Letterform Casing & Scale Architecture

The trademark McCurdy meter logotype uses a distinct hybrid casing format where the letter 'c' is rendered in lowercase while all other letters are uppercase:

McCURDY
Cap (100%) Lower (78%) Cap (100%) Cap (100%) Cap (100%) Cap (100%) Cap (100%)
  • Leading 'M': Standard capital letter, defines the $100\%$ cap height reference.
  • Lowercase 'c': Optical height is strictly $78\%$ of cap height, aligned firmly to the baseline.
  • Trailing 'CURDY': Capital letters matching the exact height, stroke weight, and optical density of the initial 'M'.
  • Tracking / Kerning: $+0.04\text{em}$ to $+0.06\text{em}$ letter spacing to prevent ink fill during precision silk-screen printing.

Approved Font Families & Fallbacks

Original McCurdy instrument faces utilized hand-drafted Swiss grotesk letterforms derived from classic Haas/Linotype Helvetica:

Priority Font Family Weight Target Environment
Primary Helvetica Neue, Helvetica 700 (Bold) Web / SVG Master Vector
Alternate 1 Arial, -apple-system 700 (Bold) Universal Cross-Platform
Alternate 2 Univers 65 / Highway Grotesk Bold High-Resolution Print Reproduction
Proportion Rule: Never render the wordmark as all-caps MCCURDY or standard sentence-case Mccurdy. The small-c baseline hybrid is the authentic proprietary mark.

05 / Usage Rules & Dial Implementation

Placement, clear space requirements, and prohibited modifications

Meter Dial Placement & Clear Space

  • Vertical Clearance: Position centered vertically between the lower 0–100% modulation scale and the bottom pivot well cap.
  • Horizontal Centerline: The top apex ($x=50$) must align exactly with the meter movement's mechanical pivot axis.
  • Minimum Clear Space: Maintain a minimum clearance zone equal to $0.5\times$ the badge height on all sides before any scale ticks or legend text.
  • Minimum Legibility Width:
    • Screen / Digital: $\ge 64\text{ px}$ width
    • Physical Faceplate Print: $\ge 14\text{ mm}$ width

Prohibited Modifications

  • No Flat Roofs: Never flatten the top or bottom ridges into a simple rectangle. The faceted peaks are essential.
  • No Capitalized 'C': Do not spell the mark as MCCURDY.
  • No Serif Typography: Never substitute serif or modern geometric circular typefaces (e.g., Futura, Times).
  • No Drop Shadows on Dial: Meter dial graphics are printed flat via precision silk-screen or photo-etching; avoid artificial heavy drop shadows on the actual dial face.

TypeScript Component (mccurdy-vu.ts helper function) 
/**
 * Render authentic McCurdy Meter Dial Cartouche Logo
 * @param cx Center X position of the meter face
 * @param cy Center Y position of the cartouche badge
 * @param scale Uniform scale factor (default: 0.92)
 * @param bgColor Cartouche body fill (e.g. '#365467' or 'none')
 * @param strokeColor Bezel outline stroke (e.g. '#D9E2E8' or ink)
 * @param textColor Wordmark text fill (e.g. '#E1E9EF' or ink)
 */
export function renderMcCurdyCartoucheLogo(
  cx: number,
  cy: number,
  scale = 0.92,
  bgColor = '#365467',
  strokeColor = '#D9E2E8',
  textColor = '#E1E9EF'
): string {
  const x = cx - 50 * scale;
  const y = cy - 16 * scale;
  return `<g id="mccurdy-dial-logo" transform="translate(${x.toFixed(1)}, ${y.toFixed(1)}) scale(${scale.toFixed(3)})">
    <path d="M 2.0,6.8 L 50.0,2.0 L 98.0,6.8 L 93.6,25.2 L 50.0,30.0 L 6.4,25.2 Z"
          fill="${bgColor}" stroke="${strokeColor}" stroke-width="1.8" stroke-linejoin="round" />
    <text x="50" y="20.5"
          font-family="'Helvetica Neue', Helvetica, Arial, sans-serif"
          font-size="13" font-weight="700" fill="${textColor}"
          text-anchor="middle" letter-spacing="0.5">
      M<tspan font-size="10.2" dy="-0.4">c</tspan><tspan font-size="13" dy="0.4">CURDY</tspan>
    </text>
  </g>`;
}
