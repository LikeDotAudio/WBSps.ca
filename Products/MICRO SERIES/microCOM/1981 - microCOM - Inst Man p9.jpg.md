The MFZD Matrix frames of the MicroCOM system form the modular building blocks, each containing up to 24 M724B Matrix Amplifiers AlI 24 balanced inputs of the M724B modules are bused together on printed circuit backplane assembly , which terminates on connectors at the rear of the MFZD frame. Each M724B Matrix Amplifier contains twenty-four solid state CMOS crosspoints, followed by an output amplifier _ This module allows the selections of any or all of the 24 Tine level inputs to be assigned and mixed to one common output_
direct input on the M724B matrix amplifier is provided for expand- ing communication buses beyond 24 inputs The outputs from success- ive matrix blocks are mixed to the inputs of primary matrix block _
The crosspoints are activated by the control system via an X-Y co-ordinate type select philosophy This control is derived from the M771 Matrix Latch Module. See the section "Central Matrix Control for further details on the operation of the crosspoints.
The audio inputs of the central matrix may be wired to jackfield to provide patching facilities_ From this point they connect to the M770 Quad Buffer Amplifier Modules which provide isolation between the matrix and the incoming sources.
These Buffer Amplifiers are housed in MFZDL mounting frame _ AII terminations to this frame are on connectors similar to the MFZD matrix blocks
The M770 Buffer Amplifier provides either bridging or matched load to the input source Four isolated outputs are provided for optional inter-matrix distribution. Test select crosspoints are provided which permit the injection of test signal into any input bus This feature is utilized in the optional matrix monitor package outlined in following section
The outputs of the MFZD matrix blocks may be wired to jackfield or terminated directly at terminal blocks at the rear of the equipment racks Additionally, the outputs may be paralleled to an optional output monitor bus _
