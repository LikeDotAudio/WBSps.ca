## Footnotes

1. No D6202B card-edge file exists; the D6202A card-edge drawing already shows the dual card (8 LEDs, EQ1 and EQ2). — `#OPENGEAR #SERIES/D6202A - #Master #OPENGEAR/D6202A - #Engineering/Functional/D6202A-card-edge.cdr`
2. The 2012 guide lists the T6303A and T6403A for the D6202B, not the T6203 modelled here. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6202B - rear module options.cdr`
3. The T6403A legend says “OUT 3 Card 2” twice; position 9 should be OUT 4 Card 2. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6202B - rear module options.cdr`
4. In the 2008 T6203 drawing the Ω was set in “WP Greek Helve” and converts as Σ (“DUAL 110ΣAES DA”); the asset was corrected. — `#OPENGEAR #SERIES/D6202A - #Master #OPENGEAR/D6202A - #Engineering/Functional/D6202B-T6203.cdr`
5. The T6203 drawing carries no issue mark, so the same artwork stands for ISS1 and ISS2/3. — `#OPENGEAR #SERIES/D6202A - #Master #OPENGEAR/D6202A - #Engineering/Functional/D6202B-T6203.cdr`
6. The D6202B T6203 drawing is filed in the D6202A engineering folder. — `#OPENGEAR #SERIES/D6202A - #Master #OPENGEAR/D6202A - #Engineering/Functional/D6202B-T6203.cdr`
