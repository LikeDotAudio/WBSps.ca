Changes in each version

What changed, in the words of the listing, oldest first.

  • V1000 — 2007|40 · 2007-11-15 — AMS16A PRODUCT REVISIONS: NONE IN THE FIELD
  • V1001 — 2008|41 · 2008-02-07 — AMS16A PRODUCT REVISIONS: 5 AT CTV (NO L,R BUTTONS)
  • V1002 — 2008|41 · 2008-08-21 — AMS16A PRODUCT REVISIONS: ADDED A LEFT ONLY, RIGHT ONLY AND A SUMMING MODE FOR DOWNMIXING CONTROL. IN THE ALTERA A MUTE PIN (ALTERA9) WAS ADDED (2 AT CTV)
  • V1003 — 2008|41 · 2008-10-29 — AMS16A PRODUCT REVISIONS: FIXED ISSUE WITH EEPROM READING AND WRITING
  • V1004 — 2008|41 · 2008-12-08 — AMS16A PRODUCT REVISIONS: FIXED COMMUNICATION BUG
  • V1005 — 2008|41 · 2008-12-20 — AMS16A PRODUCT REVISIONS: ASSIGNED FIRST AES PAIR FOR DOWNMIXING AS AES2 NOT AES1
  • V1006 — 2009|42 · 2009-01-19 — AMS16A PRODUCT REVISIONS: FIXED BUG WITH MULTI MODE MUTING A8 WHEN DOLBY IS ON A1. ALSO, DEMUX MODE AND SUMMING A8 IS ALWAYS IN8.
  • V2000 — 2009|42 · 2009-01-22 — AMS16A PRODUCT REVISIONS: ALLOWS FOR SOLOING IN 5.1 MODE (ANALOG AND AES OUTPUTS). AES8 CAN IN8 OR DOWNMIX (USED FOR SOLOING)
  • V2002 — 2009|42 · 2009-06-15 — AMS16A PRODUCT REVISIONS: FIXED BUG WITH LEFT AND RIGHT SOLOING IN MULTI MODE WHEN MULTI IS SET FOR >1.
  • V2004 — 2011|44 · 2011-01-17 — AMS16A PRODUCT REVISIONS
    • Atmel changed to fix the bug with bad values stored in eeprom for dialnorm.
    • The faulty unit came back from Systems Group, #Serial = 79409
  • v5000 — 2012|45 · 2012-01-16 — AMS16A PRODUCT REVISIONS: Prototype Version - NOT RELEASED
  • 06AV0000 — 2012|45 · 2012-10-30 — AMS16A PRODUCT REVISIONS: Sharc only up issued to match the new version format. AMS16-9 Altera only up issued to match the new vesion format
  • 06AV0001 — 2014|47 · 2014-08-20 — AMS16A PRODUCT REVISIONS: FPGA updated to fix the CRC errors in 3G format. Front atmel upissued
  • 06AV0002 — 2015|48 · 2015-07-09 — AMS16A PRODUCT REVISIONS: Front panel Atmel display initialization updated. Now compatible with PDSP1884 & HDSP2533
  • V2001 — released — AMS16A PRODUCT REVISIONS: ALLOWS FOR USER CONFIGURABLE MULTI MIX SETUP. FIXED BUG WITH SOLOING FROM SUMMING MODE APPEARING IN DEMUX MODE.
  • v2003 — undated — AMS16A PRODUCT REVISIONS
    • ams16a-3 altera: changed to shut off sdi loop through driver upon loss of lock.
    • Ams16a-2 changed to display v2.0.0.3

No change note in the listing for: V1007, V1000.
