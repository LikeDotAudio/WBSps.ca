## What it is

Ward-Beck openGear rear module that mixes BNCs with Phoenix terminal blocks. ISS1 (2006|39) had 5 BNC + 5 TB; ISS2–ISS4 (to 2008|41) became 6 BNC + 4 TB, net-for-net the same as a T6302 but still with the 15K type resistor.

## In the simulation

- ISS1 and ISS4 Gerbers, both drawn 1:1
- Layout change under one ID
- Same circuit as a T6302
- Balanced AES pairs on terminal blocks
- Pin-by-pin MEC1 route
