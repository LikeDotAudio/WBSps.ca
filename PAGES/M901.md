### General description (2)

<details><summary>Description — 2451 words · 19xx - M901 - DOC - 909-01-001 - COMPONENT LAYOUT.wp, page 1</summary><p>M909 METER/MIX MINUS MODULE</p><p>Please refer to module layout drawing A 909-04-002.</p><p>1)	Legend Strips</p><p>Two plastic covered designation strips for identification of the selector functions for the mono and stereo meter selectors.</p><p>2)	Mono Meter Selector</p><p>Momentary switches SW7 through SW12 control the active solid-state switches for source selection to the mono meter. 3)	Auxiliary Stereo Selector</p><p>Momentary switches SW1 through SW6 control the active solid-state switches for source selection to the left and right auxiliary meters. Meter Amplifiers</p><p>Main Meter Amplifier</p><p>Two identical meter amplifiers are employed for the main metering in the console. They consist of U28 and U29 and associated components for the left and right meters.</p><p>Dual operational amplifier U28 forms the nucleus of a balanced input/balanced output variable sensitivity buffer. Capacitors C74 and C75 prevent external bias from disturbing the meter circuit, while C82 and C83 protect the meter from any offset error present in U28. Trim control R129 is normally factory set to provide a 0 VU indication on the console meters at the specified system levels. Resistor R135 ensures the output impedance of the meter amplifier matches the VU standard (ANSI C16.5-1954).</p><p>Mono and Auxiliary Meter Selectors</p><p>The mono and auxiliary meters have six input sources, of which only one may be selected at a time.  Referring to the schematic on sheet B909-02-002/2, each input is AC coupled to a separate 74HC4053 solid state switch.  The outputs of the switches for the mono meter are all connected to the balanced summing amplifier U13.  R46, R48 and R52 make up the `T&#x27; feedback for U13A with potentiometer R52 providing the gain adjustment for the mono meter output.</p><p>The left and right haves of the auxiliary stereo meter selector are identical to the mono meter selector.</p><p>Meter Select Logic</p><p>Refer to the schematic on sheet B909-02-002/1.  The 74HC4053 switches are controlled by logic chips U1 through U6.  Since both the mono and auxiliary stereo logic circuits are identical, only the mono meter selector will be described.</p><p>Microcontroller U1 reads the switches SW7 through SW12, which are software debounced, and outputs a 3 bit binary code for the depressed switch with the highest precedence.</p><p>The clock rate for U1 is set by the RC time constant of R11 and C7.  U1 also requires a power on reset signal and this is provided by R17 and C5.</p><p>The tally LEDs for switches SW7 through SW12 are controlled by U4, a CD4051 8 channel analog multiplexer.  The three bit binary code from U1 determines which channel of U4 is turned &quot;ON&quot;.  Current flows through current limiting resistor R19 and through the &quot;ON&quot; channel of U4 to the appropriate LED.</p><p>Grounding the control line on pins 9, 10 &amp; 11 of the 74HC4053 will connect the associated input to the summing amplifier.  The 8 channel analog multiplexer U3 operates in manner similar to U4 except that the &quot;ON&quot; channel of U3 grounds one of the control lines to the 74HC4053 switches. The remaining control lines are pulled up by R18, which turns off the remaining 74HC4053 switches for the mono selector.  Mix Minus</p><p>Refer to the schematic on sheet B909-02-002/3.</p><p>The mix minus portion of the M909 consists of U30 through U34 and associated components. The telephone input is configured as a simple differential input amplifier whose signal is  summed  with all four mix minus outputs. The mix minus inputs are configured so that the like numbered output does not receive the associated input.</p><p>Each mix minus output is electronically balanced for direct coupling to a bridging output load. Power Supply Decoupling</p><p>The active decoupling network consisting of Q1 through Q5 and associated components regulates the incoming power for use in the module. Diodes CR1 and  CR2 prevent module damage in the event of power supply voltage reversal. The decoupling  network drops the ±23 volts down to a nominal ±18 volts.
