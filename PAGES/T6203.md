## What it is

Ten Phoenix pluggable terminal blocks for 110 Ω AES or balanced analog audio, wired to the openGear AES pairs. ISS2 (2008|41) moved the two single-ended BNC pin pairs from positions 9–10 to 1–2 so a card can take a balanced input there, without changing the 9K76 ID.

## In the simulation

- ISS3 Gerbers drawn 1:1
- D6202A, D6202B and AA6201A pinouts
- ISS1 → ISS2 pinout change, same ID
- Balanced input on BNCx_SIG / BNCx_GND pins
- Card-side ID read
