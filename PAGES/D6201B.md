## Footnotes

1. CARD 1 sits on the left of the T6401A in the 2008 drawing. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201B Rear Mod.cdr`
2. The 2012 guide marks “2 CARD 1”, so CARD 1 moved to the right (even positions); the simulator follows 2012. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6201B - rear module options.cdr`
3. The D6201B card edge has 8 LEDs and two EQ switches (EQ1, EQ2). — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201B-card-edge.cdr`
4. The D6202A card-edge drawing is identical to the D6201B one apart from the ejector label. — `#OPENGEAR #SERIES/D6202A - #Master #OPENGEAR/D6202A - #Engineering/Functional/D6202A-card-edge.cdr`
5. The 2006 T6201/T6301 label sheets, filed as D6201A, are already labelled for the dual card (“DUAL 75Ω AES DA”, IN1/IN2). — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201A-T6201.cdr`
6. The 2008 sheet titles the T6201 “SINGLE CARD REAR MODULE FOR DFR-8310” and the T6301A/T6401A “FOR DFR-8320”. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201B Rear Mod.cdr`
7. The 2012 guide footer reads “D6201B-1x8 / 2x4 AES DA 75 Ohm” for the T6301A. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6201B - rear module options.cdr`
