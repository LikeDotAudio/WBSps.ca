3. The 2006 T6201 label sheet is titled “DUAL 75Ω AES DA” with IN1/IN2, i.e. drawn for the dual-channel card. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201A-T6201.cdr`
4. The 2006 T6301 label sheet is also labelled for the dual card (IN1/IN2, OUT1-x/OUT2-x), two years before the D6201B shipped. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201A-T6301.cdr`
5. The 2006 label sheets draw only BNC 1 and 2; positions 3–10 are just numbers. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201A-T6401.cdr`
6. CARD 1 sits on the left of the T6401A in the 2008 drawing. — `#OPENGEAR #SERIES/D6201  # Problem is this the same as A #OPENGEAR/D6201 - #Engineering/D6201A/Functional/D6201B Rear Mod.cdr`
7. The 2012 guide marks “2 CARD 1”, so CARD 1 moved to the right (even positions); the simulator follows 2012. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6201A - rear module options.cdr`
8. The guide's T6301A legend reads “Not Connected” at position 2. — `#OPENGEAR #SERIES/#OPEN GEAR - #Engineering/OPEN GEAR - #Engineering/openGear Rear Module Guides/D6201A - rear module options.cdr`
